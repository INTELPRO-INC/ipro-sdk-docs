音訊與多媒體

IPRO SDK 提供完整的音訊與多媒體功能，涵蓋 LE Audio 藍牙音訊、USB 音訊裝置、攝影機影像處理及視訊串流。本頁面介紹各子系統的架構、API 及參考應用程式。

概述

IPRO7 SoC 整合多種音訊與多媒體硬體加速器，搭配 SDK 軟體堆疊，支援以下功能：

LE Audio

LE Audio (BLE 5.2+)

  • LC3 編解碼器（liblc3）
  • 單播 (CIS) 與廣播 (BIS)
  • BAP / CAP / VCP / MCP 協定
  • Auracast 廣播音訊
USB

USB 音訊 (UAC)

  • USB Audio Class 裝置
  • USB 轉 BLE 音訊橋接
  • CherryUSB 整合
  • 低延遲音訊傳輸
CAM

攝影機與視訊

  • ISP 影像訊號處理
  • MJPEG 硬體編碼
  • UVC USB 攝影機裝置
  • LCD 顯示輸出

LE Audio 音訊管線

LE Audio 是 BLE 5.2 引入的次世代藍牙音訊標準，使用 ISO Channel（等時通道）傳輸音訊資料，取代傳統 Classic Audio 的 A2DP/HFP。

傳送端管線

1
Audio Input
AUADC / I2S PCM 取樣
2
LC3 編碼
音訊編碼 16-320 kbps
3
ISO Channel
CIS 或 BIS 等時通道
4
BLE PHY
2M PHY 無線傳輸

接收端管線

1
BLE PHY
2M PHY 無線接收
2
ISO Channel
CIS 或 BIS 資料重組
3
LC3 解碼
音訊解碼 PCM 還原
4
Audio Output
DAC / I2S 喇叭輸出

關鍵特性

特性說明
編碼器LC3（由 prebuilt 函式庫 liblc3 提供）
位元率16 - 320 kbps（LE Audio 常用 16-124 kbps/聲道）
取樣率8 / 16 / 24 / 32 / 48 kHz
聲道單聲道、立體聲
延遲< 20ms 端到端
傳輸模式CIS（單播）、BIS（廣播）

單播音訊 (CIS)

Connected Isochronous Stream（CIS）提供點對點的雙向音訊傳輸，適用於耳機、助聽器等需要穩定連線的場景。

CIS 架構

Unicast Server (耳機端)
BAP Acceptor VCP Renderer MCC Client CAP Acceptor
CIS (LC3 Audio Stream)
Unicast Client (手機端)
BAP Initiator VCP Controller MCS Server CAP Initiator

BAP 單播流程

Basic Audio Profile（BAP）負責管理音訊串流的建立與控制，流程如下：

1
Discover PACS
查詢支援的音訊能力
2
PAC Records
回傳編碼器/取樣率
3
Configure ASE
設定音訊串流端點
4
Establish CIS
建立等時通道
5
Enable Stream
啟動音訊傳輸

耳機端範例程式碼

BAP Server 初始化 (apps/bluetooth/le_audio/ipro_le_audio_headset/src/bap_server.c) 
/* 註冊 BAP Unicast Server 回呼 */
static const struct bt_bap_unicast_server_cb unicast_server_cb = {
    .config = bap_server_config,
    .reconfig = bap_server_reconfig,
    .qos = bap_server_qos,
    .enable = bap_server_enable,
    .start = bap_server_start,
    .metadata = bap_server_metadata,
    .disable = bap_server_disable,
    .stop = bap_server_stop,
    .release = bap_server_release,
};

int bap_server_init(void)
{
    /* 初始化 PACS 服務（須先於 ASCS） */
    bt_pacs_init();

    /* 註冊 LC3 sink 音訊能力 */
    bt_pacs_cap_register(BT_AUDIO_DIR_SINK, &lc3_sink_cap);

    /* 設定音訊位置與 audio context */
    bt_pacs_set_location(BT_AUDIO_DIR_SINK, BT_AUDIO_LOCATION_FRONT_LEFT);
    bt_pacs_set_supported_contexts(BT_AUDIO_DIR_SINK,
                                   BT_AUDIO_CONTEXT_TYPE_MEDIA |
                                   BT_AUDIO_CONTEXT_TYPE_CONVERSATIONAL |
                                   BT_AUDIO_CONTEXT_TYPE_UNSPECIFIED);

    /* 向 ASCS 註冊 Unicast Server 回呼 */
    bt_bap_unicast_server_register_cb(&unicast_server_cb);

    return 0;
}

音訊協定

LE Audio 定義了多個協作的協定（Profile），共同管理音訊串流的各個面向：

協定全稱功能原始碼
BAP Basic Audio Profile 音訊串流建立與管理（CIS/BIS） ipro_bt_host/upstream/zephyr/subsys/bluetooth/audio/bap_*.c
CAP Common Audio Profile 協調集合音訊操作（左右耳同步） ipro_bt_host/upstream/zephyr/subsys/bluetooth/audio/cap_*.c
VCP Volume Control Profile 音量控制與靜音 ipro_bt_host/upstream/zephyr/subsys/bluetooth/audio/vcp_*.c
MCP Media Control Profile 媒體播放控制（播放/暫停/曲目） ipro_bt_host/upstream/zephyr/subsys/bluetooth/audio/mcc.c, mcs.c
CSIP Coordinated Set Identification Profile 識別裝置集合（如一對耳機） ipro_bt_host/upstream/zephyr/subsys/bluetooth/audio/csip_*.c
PACS Published Audio Capabilities Service 公佈支援的音訊能力 ipro_bt_host/upstream/zephyr/subsys/bluetooth/audio/pacs.c
ASCS Audio Stream Control Service 音訊串流端點狀態機 ipro_bt_host/upstream/zephyr/subsys/bluetooth/audio/ascs.c
MICP Microphone Control Profile 麥克風靜音控制 ipro_bt_host/upstream/zephyr/subsys/bluetooth/audio/micp_*.c
TMAP Telephony and Media Audio Profile 電話與媒體音訊角色定義 ipro_bt_host/upstream/zephyr/subsys/bluetooth/audio/tmap.c

LC3 編解碼器

LC3（Low Complexity Communication Codec）是 LE Audio 的必備編解碼器，以較低位元率提供優於 SBC 的音質。SDK 以 prebuilt 函式庫 components/3rdparty/liblc3 提供 LC3 編解碼；ipro_bt_host/upstream/zephyr/subsys/bluetooth/audio/codec.c 負責 LE Audio codec 能力與設定的解析。

  • 取樣率：8 / 16 / 24 / 32 / 48 kHz
  • 位元率：16 - 320 kbps（LE Audio 常用 preset 為每聲道 16 - 124 kbps）
  • 幀長度：LE Audio 標準為 7.5ms 或 10ms；隨附的 liblc3 另支援 2.5ms 與 5ms
  • 聲道：單聲道、立體聲
  • 優勢：以 160 kbps 達到 SBC 328 kbps 的音質
Opus: 交付包包含 components/3rdparty/opus，供應用音訊編解碼使用。LE Audio ISO 串流使用 LC3；先前的語音助理範例未隨附於 V1.2.1。

#include "usbd_core.h"
#include "usbd_audio.h"

/* USB 主機開啟音訊串流（Set Alternate Setting）時由 CherryUSB 呼叫 */
void usbd_audio_open(uint8_t intf)
{
    /* 啟動等時傳輸 DMA；尚無音訊資料時先送出靜音 */
}

void usbd_audio_close(uint8_t intf)
{
    /* USB 主機關閉音訊串流 */
}

/* 初始化 USB Audio 裝置 */
int app_uac_init(const app_uac_config_t *config)
{
    usbd_desc_register(uac_descriptor);
    usbd_add_interface(usbd_audio_init_intf(&s_intf0, 0x0100, s_entity_table, 1));
    usbd_add_interface(usbd_audio_init_intf(&s_intf1, 0x0100, s_entity_table, 1));
    usbd_add_endpoint(&s_audio_in_ep);
    usbd_event_register_callback(uac_event_handler);
    usbd_initialize();
    return 0;
}

音訊硬體

IPRO7 SoC 整合多個音訊硬體周邊，透過 HAL 層提供統一的存取介面：

硬體功能HAL 標頭說明
AUADC 音訊 ADC hal_auadc.h 內建音訊類比數位轉換器，直接連接麥克風
DAC 數位類比轉換器 hal_dac.h 音訊輸出至喇叭或耳機
I2S Inter-IC Sound hal_i2s.h 連接外部音訊編解碼晶片的數位音訊介面
DMA 直接記憶體存取 hal_dma.h 零 CPU 負載的音訊資料搬移

音訊硬體資料流

音訊硬體資料路徑 
錄音路徑（輸入）：
  麥克風 → AUADC → DMA → 記憶體緩衝區 → LC3 編碼器 / USB

播放路徑（輸出）：
  LC3 解碼器 / USB → 記憶體緩衝區 → DMA → DAC → 喇叭

外部編解碼器路徑：
  外部 Codec ↔ I2S ↔ DMA ↔ 記憶體緩衝區

Audio Output 抽象層

components/audio 提供統一的音訊輸出抽象層 audio_output，以同一組 API 操作 DAC、I2S、UAC 與 PCM dump 等多種後端，是 LE Audio 參考應用實際使用的輸出介面。同元件另提供 audio_capture（AUADC + DMA 音訊擷取）與 mp3_decoder（MP3 解碼）：

音訊輸出抽象層 (components/audio/include/audio_output.h) 
#include "audio_output.h"

audio_output_cfg_t cfg = {
    .type        = AUDIO_OUTPUT_DAC,            /* DAC / UAC / I2S / DUMP */
    .mode        = AUDIO_OUTPUT_MODE_STREAMING,
    .sample_rate = 48000,
    .channels    = 2,
};

audio_output_t *out = audio_output_create(&cfg);
audio_output_start(out);
audio_output_write(out, pcm, samples);   /* interleaved int16_t PCM */
audio_output_stop(out);
audio_output_destroy(out);

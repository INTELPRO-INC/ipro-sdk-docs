Zephyr RTOS

自 IPRO SDK V2.1.0 起，SDK 同時是一個 Zephyr v4.4.0 模組：同一套 HAL 與 SoC 驅動程式以 Zephyr 的裝置驅動程式 API 提供，應用程式可以直接以 Zephyr 開發。FreeRTOS 應用與建構流程維持不變，請見快速開始。

概覽

  • SDK 根目錄的 west.yml 讓 SDK 成為 west 的 manifest repository，zephyr/module.yml 把 SDK 註冊為 Zephyr 模組（板卡、SoC、裝置樹與驅動程式都在 zephyr/）。
  • Zephyr 的驅動程式建立在 SDK 的 HAL 之上；HAL 直接從 bsp/ 編譯，不另外複製一份。
  • Bluetooth LE 使用 Zephyr 的 Host 搭配 IPRO BLE Controller；IEEE 802.15.4 使用 Zephyr 的驅動程式介面與 OpenThread。

支援板卡

Zephyr board硬體
ipro7_evbIPRO7 EVB
ipro7ai_evkIPRO7AI EVK
ipro6s_evb 的板卡檔案隨附於 SDK，但此版本的 Zephyr 不支援 IPRO6S。IPRO7AI Reef EVK 目前沒有 Zephyr 板卡定義，請使用 FreeRTOS 應用。

建立 Workspace

需要 Python 3.10 以上、CMake 3.20 以上、Ninja、git、dtc，以及 IPRO RISC-V 工具鏈（預設 /opt/toolchain/riscv_ipro7，可用 IPRO_TOOLCHAIN 指定）。第一次建立時需要連上 GitHub。

tools/zephyr/bootstrap.sh          # 在 zephyr-workspace/ 建立 west workspace
source zephyr-workspace/env.sh     # ZEPHYR_BASE、CROSS_COMPILE、west

bootstrap.sh 會下載 Zephyr v4.4.0 與 west.yml 列出的模組（mbedTLS、tf-psa-crypto、OpenThread、MCUboot、LC3、zcbor、picolibc、SEGGER RTT），並套用 zephyr/patches.yml 列出的 Zephyr 修補。

建構、燒錄與 Console

cd zephyr-workspace
west build -b ipro7_evb zephyr/samples/hello_world                       # Zephyr 範例
west build -b ipro7_evb ../zephyr/samples/periph_smoke -d build/smoke     # SDK 範例
west flash                                                               # IntelProCube 命令列工具
  • west flash 使用 IntelProCube 命令列工具：由 IPRO_FLASH_TOOL 指定，或放在 PATH 上。
  • 預設透過 IPRO7 CMSIS-DAP probe 進入下載模式；沒有 probe 時用 west flash -- --boot shell（由執行中韌體的 reboot_dl 進入）或 --boot manual。
  • 序列埠用 --port 或 IPRO_SERIAL_PORT 指定；只接一個 USB 序列埠時會自動選用。
  • Zephyr 的 Console 在 UART0，速率 2,000,000 baud；tools/zephyr/monitor.sh 可直接開啟。

# BLE 心率周邊
west build -b ipro7_evb zephyr/samples/bluetooth/peripheral_hr -- \
    -DEXTRA_CONF_FILE=$PWD/../zephyr/samples/bt_peripheral_hr/ipro7.conf \
    -DEXTRA_DTC_OVERLAY_FILE=$PWD/../zephyr/samples/bt_peripheral_hr/ipro7.overlay

# OpenThread shell
west build -b ipro7_evb zephyr/samples/net/openthread/shell -- \
    -DEXTRA_CONF_FILE=$PWD/../zephyr/samples/ieee802154_shell/ot.conf \
    -DEXTRA_DTC_OVERLAY_FILE=$PWD/../zephyr/samples/ieee802154_shell/app.overlay

預編譯元件

除下列元件外，Zephyr 建構時所有 SDK 程式（包含 HAL）都從原始碼編譯：

  • BLE Controller：components/wireless/bluetooth/ipro_ble_controller/lib/
  • RF 驅動程式：components/wireless/rf/ipro7_rf/lib/zephyr/
  • IEEE 802.15.4 MAC：components/wireless/ieee802154/lib/zephyr/

RF 與 802.15.4 的預編譯函式庫各有兩個版本；連結 BLE Controller 時整個映像檔以 -fshort-enums 編譯，建構系統會自動選用相符的版本。

尚未支援

  • 低功耗模式：尚未透過 Zephyr 的 pm_state 進入 PDS／HBN，BLE Controller 也不會進入睡眠。
  • 顯示器、相機、音訊 codec、USB、SD host、Ethernet 與 NPU 的 Zephyr 驅動程式（IPRO7AI EVK 的 LCD 可透過 Zephyr 內建的 ST7789V 驅動程式使用）。

以上功能請使用 FreeRTOS 應用，FreeRTOS 仍是正式量產使用的 RTOS。

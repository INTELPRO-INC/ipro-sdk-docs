網路開發

IPRO7 是系統的主控 SoC，負責應用邏輯、NPU 推論與 BLE 連線，本身不內建 Wi-Fi。IPRO SDK V2.1.0 透過 lwIP TCP/IP 協定堆疊與 mbedTLS 加密程式庫，在 IPRO7 上提供下列對外連網路徑：

  • 乙太網路 — IPRO7 內建 Ethernet MAC 控制器 (EMAC，RMII)，搭配 lwIP 即可有線上網，參考應用為 ipro7_demo；另附 ipro_enc28j60_test（ENC28J60 經 SPI）。
  • Wi-Fi（IPRO6S 作為 SDIO 無線端） — IPRO7 經 SDIO 驅動執行 Wi-Fi 韌體的 IPRO6S，連線呈現為 lwIP netif iproeth0。IPRO7 端隨 SDK 提供：ipro7_sdio_wifi（ipronet_host 的 SDIO host 範例：傳輸、netif、DHCP、iperf），以及 IPRO7AI Reef EVK 搭配 IPRO6S FIN 卡的 ipro7ai_reef_demo（defconfig_wifi_ipro6s，含 RTSP 相機串流）。IPRO6S 端韌體不在 V2.1.0 內：ipro6_if_wifi 隨 V2.0.1 提供，FIN 卡韌體請洽 INTELPRO。
  • ATBM6162 SDIO 模組 — V2.1.0 只附模組探測程式 ipro_atbm_probe。

V2.1.0 未包含 LTE modem 元件 components/network/lte_modem/。V2.1.0 不支援 IPRO6S 建置；IPRO6S 晶片內建 Wi-Fi 6 的開發請使用 V2.0.1。本頁內容適用於 FreeRTOS 應用；Zephyr RTOS 目前沒有 Ethernet 驅動，Thread 請見 Matter & Thread。

網路架構

IPRO SDK 的網路子系統採用分層架構。EMAC 與 SDIO Wi-Fi 共用同一個 lwIP 堆疊，應用層程式碼不需因實體介面不同而改寫：

網路配置

在應用程式的 .config 檔案中啟用網路相關功能：

.config - 網路配置 
# 啟用 lwIP TCP/IP 堆疊
CONFIG_COMPONENTS_LWIP_ENABLE=y
CONFIG_COMPONENTS_LWIP_APP_ENABLE=y

# 啟用 ping 指令 (網路診斷)
CONFIG_PING=y

# 啟用乙太網路 (EMAC)
CONFIG_ETHERNET=y

# 啟用 mbedTLS 加密支援
CONFIG_COMPONENTS_MBEDTLS_ENABLE=y
提示：以上配置與 Release SDK 內的 apps/platform/ipro7_demo 一致，可直接以該專案的 .config 為起點。

lwIP 整合

IPRO SDK 整合 lwIP (Lightweight IP) 作為 TCP/IP 協定堆疊，提供標準的 BSD Socket API，讓開發者可以使用熟悉的 socket 程式設計介面。

Socket API 範例

TCP 用戶端連線 
#include <lwip/sockets.h>
#include <lwip/netdb.h>

int tcp_client_example(const char *host, uint16_t port)
{
    struct sockaddr_in server_addr;
    int sock;

    /* 建立 TCP socket */
    sock = socket(AF_INET, SOCK_STREAM, 0);
    if (sock < 0) {
        printf("Socket 建立失敗\r\n");
        return -1;
    }

    /* DNS 解析主機名稱 */
    struct hostent *hp = gethostbyname(host);
    if (!hp) {
        printf("DNS 解析失敗: %s\r\n", host);
        close(sock);
        return -1;
    }

    /* 連線至伺服器 */
    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_port = htons(port);
    memcpy(&server_addr.sin_addr, hp->h_addr, hp->h_length);

    if (connect(sock, (struct sockaddr *)&server_addr,
                sizeof(server_addr)) < 0) {
        printf("連線失敗\r\n");
        close(sock);
        return -1;
    }

    /* 傳送資料 */
    const char *msg = "Hello from IPRO7!";
    send(sock, msg, strlen(msg), 0);

    /* 接收回應 */
    char buf[256];
    int len = recv(sock, buf, sizeof(buf) - 1, 0);
    if (len > 0) {
        buf[len] = '\0';
        printf("收到回應: %s\r\n", buf);
    }

    close(sock);
    return 0;
}
UDP 傳送範例 
#include <lwip/sockets.h>

int udp_send_example(const char *dest_ip, uint16_t port)
{
    int sock = socket(AF_INET, SOCK_DGRAM, 0);
    if (sock < 0) return -1;

    struct sockaddr_in dest;
    memset(&dest, 0, sizeof(dest));
    dest.sin_family = AF_INET;
    dest.sin_port = htons(port);
    inet_aton(dest_ip, &dest.sin_addr);

    const char *data = "UDP packet from IPRO7";
    sendto(sock, data, strlen(data), 0,
           (struct sockaddr *)&dest, sizeof(dest));

    close(sock);
    return 0;
}

乙太網路

IPRO7 內建 EMAC (Ethernet MAC) 控制器，以 RMII 外接 Ethernet PHY 即可支援有線網路連線，適用於閘道器、工業控制等需要有線網路的應用場景。這是 V2.1.0 中不需外接 Wi-Fi 模組的連網路徑。

EMAC 初始化與 lwIP 註冊 
#include <hal_emac.h>
#include <hal_ethernetif.h>
#include <lwip/tcpip.h>

static struct netif emac_netif;

static void emac_netif_setup(void *arg)
{
    struct netif *netif = (struct netif *)arg;
    ip4_addr_t ipaddr, netmask, gw;

    /* 使用 DHCP (位址設為 0) */
    ip_addr_set_zero(&ipaddr);
    ip_addr_set_zero(&netmask);
    ip_addr_set_zero(&gw);

    /* 註冊網路介面 */
    netif_add(netif, &ipaddr, &netmask, &gw,
              NULL, ethernetif_init, tcpip_input);
    netif_set_default(netif);
    ethernet_link_status_updated(netif);

    /* 啟動 DHCP 用戶端 */
    netifapi_dhcp_start(netif);
}

void emac_init(void)
{
    memset(&emac_netif, 0, sizeof(emac_netif));
    tcpip_init(emac_netif_setup, &emac_netif);
}

啟用乙太網路需在 .config 中設定 CONFIG_ETHERNET=y，驅動位於 bsp/drivers/ipro7_soc/std_drv/src/drv_emac.c。參考應用 apps/platform/ipro7_demo 在開機時自動執行 emac_lwip 指令完成上述流程。

沒有 RMII PHY 的板子可參考 apps/test/ipro_enc28j60_test/（ENC28J60 乙太網路控制器經 SPI）。此範例確認晶片、設定 MAC／PHY 並以 shell 收發原始乙太網路封包，未整合 lwIP；接線請見該範例的 README。

TLS／DTLS（mbedTLS）

本版附 mbedTLS 2.28.2，以 CONFIG_COMPONENTS_MBEDTLS_ENABLE=y 啟用；實際演算法由選用的設定標頭決定。版本號代表隨 SDK 交付的版本。

TLS client 可參考已附的 components/crypto/mbedtls/mbedtls/programs/ssl/ssl_client1.c，移植時完成下列步驟：

  1. 初始化 entropy 與 CTR-DRBG，確認平台提供有效的熵來源，並檢查每個初始化與連線呼叫的回傳值。
  2. 載入目標服務信任的 CA 憑證，以 mbedtls_ssl_conf_ca_chain() 設定，並使用 MBEDTLS_SSL_VERIFY_REQUIRED。
  3. 以 mbedtls_ssl_set_hostname() 設定實際主機名稱；平台時間需能正確驗證憑證有效期。
  4. 握手與讀寫時處理 MBEDTLS_ERR_SSL_WANT_READ／MBEDTLS_ERR_SSL_WANT_WRITE、部分傳輸及逾時；成功後確認憑證驗證結果。
  5. HTTP Host 必須對應連線目標，處理回應後關閉 TLS 與 socket，所有錯誤路徑都釋放資源。

上游範例的測試憑證與主機需替換成產品實際設定；它是移植參考，不會自動為開發板設定網路或信任憑證。

HTTP Client

V2.1.0 未附 components/http_client/ 高階用戶端。開發 HTTP／HTTPS 時，以已附的 lwIP 與 mbedTLS 建立傳輸，或另行整合相容的 HTTP 函式庫；請處理 HTTP 狀態碼、分塊傳輸、長度限制與逾時。

Wi-Fi（IPRO6S 作為 SDIO 無線端）

IPRO7 不內建 Wi-Fi。components/network/ipronet_host/ 是 IPRO7 端的 SDIO host：IPRO7 經 SDH 控制器驅動執行 Wi-Fi 韌體的 IPRO6S，並把連線呈現為 lwIP netif iproeth0，由 IPRO7 負責 IP 堆疊。V2.1.0 附兩個 IPRO7 端應用：

  • apps/platform/ipro7_sdio_wifi/：ipronet_host 的 SDIO host 範例（傳輸、netif、DHCP、iperf）。IPRO6S 端韌體 ipro6_if_wifi 不在 V2.1.0 內，請使用 V2.0.1 建置，或洽 INTELPRO。
  • apps/platform/ipro7ai_reef_demo/ 的 defconfig_wifi_ipro6s：在 IPRO7AI Reef EVK 的卡槽插入 IPRO6S FIN 卡，加入 Wi-Fi 與 RTSP 相機串流（components/network/rtsp_server/）。FIN 卡上的韌體不在 V2.1.0 內，請洽 INTELPRO。
./build_freertos.sh ipro7_sdio_wifi build
make -C apps/platform/ipro7ai_reef_demo DEFCONFIG=defconfig_wifi_ipro6s

輸出分別位於 apps/platform/ipro7_sdio_wifi/build/build_out/ipro7_sdio_wifi_IPRO7.bin 與 apps/platform/ipro7ai_reef_demo/build_wifi_ipro6s/build_out/。Reef 燒錄時選用 --chip-variant IPRO7AI 與 partition_cfg_2M.toml，板子設定見硬體參考。燒錄前確認板子接線與 IPRO6S 的電源控制。

ipronet_up <SSID> <PASSWORD>
ipronet_down
rtsp_cam on

上述指令於 IPRO7 序列埠（115200 baud）執行；rtsp_cam on 只在 Reef 的 defconfig_wifi_ipro6s 中提供，開始相機串流，位址為 rtsp://<ip>:8554/av0_0。components/network/ipronet_host/ipronet_host.h 提供 ipronet_config_default()、ipronet_start() 與 ipronet_connect()；收到 on_got_ip 後才使用 socket。RX task 回呼應將工作交給應用 task，不可阻塞或直接呼叫連線控制 API。

ATBM6162 SDIO 模組

外接 ATBM6162 Wi-Fi 模組時，IPRO7 以 SDH 控制器作為 SDIO host，模組驅動位於 components/wireless/wifi_atbm6162/。V2.1.0 只附模組探測程式 apps/test/ipro_atbm_probe/，用於模組上電、SDIO 列舉、韌體下載與握手的確認。

./build_freertos.sh ipro_atbm_probe build

模組的供電、致能與 SDIO 接線依載板而定；燒錄前請對照探測程式原始碼中的板級設定確認接線。

IPRO6S Wi-Fi 6（V2.0.1）

V2.1.0 不含 IPRO6S 應用，也不支援 IPRO6S 建置；IPRO6S 晶片內建 Wi-Fi 6 的獨立連網開發請使用 V2.0.1。在 V2.0.1 中以 apps/platform/ipro6_demo/ 為起點，配置啟用 CONFIG_WIFI6=y 與 CONFIG_USE_MACSW=y。

Core Features

IPRO SDK provides a complete embedded development ecosystem, from low-level drivers to high-level applications

Image Processing

Integrated ISP image pipeline, MJPEG encoding, LCD display driver for camera streaming and image recognition applications.

Voice Processing

Built-in AUADC/DAC audio subsystem with LC3 codec support, LE Audio streaming for voice recognition and audio devices.

BLE Wireless

High-performance BLE communication (up to 999 Kbps), LE Audio support, multi-link management, and OTA firmware updates.

Modular Architecture

Clean layered architecture: Application, Middleware, RTOS, BSP. Components are configured independently through the Kconfig system.

Development Toolchain

make -C apps/<project> quick build, build_freertos.sh build script, CMake toolchain integration, and the tools/serial_monitor.py serial console reader.

Zephyr RTOS

The SDK is also a Zephyr v4.4.0 module for the IPRO7 EVB and IPRO7AI EVK: peripheral drivers, BLE, IEEE 802.15.4 / OpenThread (Thread) and MCUboot.

Windows Online Installer 3.4.0: setup and independent updates · Extension 3.3.0: Control Center, Build / Flash / Monitor

Quick Start

Choose your preferred development approach and start building in minutes

FreeRTOS Build Commands 
# Use Make build (recommended)
make -C apps/bluetooth/ble/ipro_ble_remote

# Or use build script
./build_freertos.sh ipro_ble_remote build
Tip: Build output is located in apps/<category>/<name>/build/build_out/ directory.
Zephyr RTOS (IPRO7 EVB / IPRO7AI EVK) 
tools/zephyr/bootstrap.sh
source zephyr-workspace/env.sh
cd zephyr-workspace
west build -b ipro7_evb zephyr/samples/hello_world
west flash
FreeRTOS is the main development path; all 35 applications build with FreeRTOS. For Zephyr host requirements, flashing and supported scope, see Zephyr RTOS.

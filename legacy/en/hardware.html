IPRO6S

IPRO6S builds are not supported in V2.1.0: this release includes no IPRO6S applications, no IPRO6S BLE controller archives and no ipro6_rf. For IPRO6S development, use V2.0.1; the IPRO6S information in this section applies to V2.0.1.

In V2.0.1, IPRO6S works as a standalone Wi-Fi 6 / Bluetooth dual-mode SoC and as the SDIO radio for IPRO7. It uses CONFIG_IPRO6=y and the same RISC-V toolchain target, CONFIG_CPU_ID="intelpro_ipro7". It does not provide the IPRO7 NPU / ISP.

IPRO7 Chip Overview

2.4G Low-Power Wireless Chip

IPRO7 is a wireless chip designed for low-power IoT applications, supporting BLE 5.4 and LE Audio, with a built-in ISP image processor and 0.1 TOPS NPU accelerator for wearables, audio products, and IoT devices.

BLE 5.4 LE Audio ISP NPU 0.1 TOPS

MCU Processor

  • RISC-V RV32IMAFC @192MHz
  • L1 I/D Cache 16KB/16KB
  • OCRAM 256KB (plus 4KB HBN retention RAM)
  • ROM 128KB
  • eFuse 2Kb
  • RTC, Timer x2, WDT
  • DMA 8 Channels

Memory Configuration

  • Flash size depends on the board (e.g. 2 MB on the IPRO7AI Reef EVK)
  • Built-in 64Mb (8MB) pSRAM
  • XIP QSPI Support
  • On-The-Fly AES Decryption (OTFAD)
  • External QSPI Flash Support

  • Bluetooth 5.4 / BLE

UART Pin Assignment (Function = 7)

GPIO20/GPIO21 are used by Boot ROM UART download. Application console baud rate comes from each application's CONFIG_PLATFORM_UART_BAUDRATE (default 115200); a board has no fixed console baud. The default configurations of ipro7ai_evk_demo, ipro7ai_evk_launcher, ipro7ai_evk_rps, ipro_meeting_poc, ipro7_uvc_cam and ipro_epd_el036, and the EVK configuration of ipro_pdm_mic_demo (config_evk), use 921600; other applications and the IPRO7AI Reef EVK configurations (console on the U6 connector) use 115200.

UART uses a two-stage mux: (1) set the GPIO to function 7 to generate UART_SIG_N, (2) route the signal to UART0/UART1 TX/RX/CTS/RTS via GLB_UART_Fun_Sel(). Any GPIO can serve as UART.

UART Configuration Example

/* Use GPIO14 as UART1_TXD, GPIO15 as UART1_RXD */
GLB_GPIO_Cfg_Type uart_pins[] = {
    { GLB_GPIO_PIN_14, GPIO_FUN_UART, GPIO_MODE_AF, GPIO_PULL_UP, 0, 1 },
    { GLB_GPIO_PIN_15, GPIO_FUN_UART, GPIO_MODE_AF, GPIO_PULL_UP, 0, 1 },
};
GLB_GPIO_Init(&uart_pins[0]);
GLB_GPIO_Init(&uart_pins[1]);

/* GPIO14 -> UART_SIG_2, GPIO15 -> UART_SIG_3 (SIG = GPIO number mod 12) */
GLB_UART_Fun_Sel(GLB_UART_SIG_2, GLB_UART_SIG_FUN_UART1_TXD);
GLB_UART_Fun_Sel(GLB_UART_SIG_3, GLB_UART_SIG_FUN_UART1_RXD);

SPI Configuration Example

/* SPI0 on GPIO12~15 group */
GLB_GPIO_Cfg_Type spi_pins[] = {
    { GLB_GPIO_PIN_12, GPIO_FUN_SPI, GPIO_MODE_AF, GPIO_PULL_NONE, 1, 1 }, /* MOSI */
    { GLB_GPIO_PIN_13, GPIO_FUN_SPI, GPIO_MODE_AF, GPIO_PULL_NONE, 1, 1 }, /* MISO */
    { GLB_GPIO_PIN_14, GPIO_FUN_SPI, GPIO_MODE_AF, GPIO_PULL_UP,   1, 1 }, /* SS   */
    { GLB_GPIO_PIN_15, GPIO_FUN_SPI, GPIO_MODE_AF, GPIO_PULL_NONE, 1, 1 }, /* SCLK */
};
for (int i = 0; i < 4; i++) GLB_GPIO_Init(&spi_pins[i]);

SDIO / SD Card Pin Assignment (Function = 27)

GPIO28~33 are shared between SDC and SF2/SF3 — when CONFIG_DISABLE_SDC_PINMUX is defined, these pins are repurposed for external flash and cannot be used for an SD card at the same time.

Pin Conflicts and Design Notes

  • GPIO20/21: preserve the board connections required for Boot ROM UART download; application console behavior follows board and application configuration.
  • GPIO0~2, GPIO11: JTAG debug by default; can be freed for use in production designs
  • GPIO17~22: check flash/peripheral conflicts against the package, flash configuration and board schematic; pin numbers alone do not establish availability.
  • GPIO23~28: shared with external flash (SF2); watch for conflicts
  • GPIO28~33: SDC and SF2/SF3 are mutually exclusive, selected by CONFIG_DISABLE_SDC_PINMUX

Peripheral Connection Guide

I2S Audio Codec

Connect an external audio codec (e.g., ES8388, WM8978). Uses I2S Group 1 (GPIO4~7) + I2C0 for control.

IPRO7 Function Codec
GPIO4 (Fun=3, I2S0_BCLK) I2S Bit Clock BCLK
GPIO5 (Fun=3, I2S0_FS) I2S Frame Sync LRCLK / WS
GPIO6 (Fun=3, I2S0_DO) I2S Data Out DIN (to codec)
GPIO7 (Fun=3, I2S0_DI) I2S Data In DOUT (from codec)
GPIO12 (Fun=6, I2C0_SCL) I2C Clock SCL
GPIO13 (Fun=6, I2C0_SDA) I2C Data SDA

I2S can also use any other group (0~7); each group of 4 pins is BCLK/FS/DO/DI in order. See I2S Pin Assignment.

SPI Peripherals (LCD / Sensor)

SPI0 connects an LCD or sensors. Uses Group 3 (GPIO12~15).

IPRO7 Function Peripheral
GPIO15 (Fun=4, SPI0_SCLK) SPI Clock SCK
GPIO12 (Fun=4, SPI0_MOSI) SPI Master Out SDI / MOSI
GPIO13 (Fun=4, SPI0_MISO) SPI Master In SDO / MISO
GPIO14 (Fun=4, SPI0_SS) Chip Select CS#

MOSI/MISO can be swapped via pin_swap_enable. SPI0 supports 8 pin groups; see SPI Pin Assignment.

I2C0 sensor connection example. I2C0 can use any even/odd GPIO pairing (SCL = even pin, SDA = odd pin).

Design Recommendations

Input Protection

Add TVS (SMAJ15CA) for 12V input ESD/surge protection

Decoupling Capacitors

Place 100nF decoupling capacitor on each power pin, close to IC

Bulk Capacitors

Place 10μF~47μF capacitor on +5V and +3.3V rails

Power Sequencing

Follow the power sequencing specified for the exact chip and board revision

Ground Planning

Use solid ground plane, separate analog/digital regions

LDO Selection

Use low-noise LDO for analog power (AVDD)

Current Measurement

The SDK does not establish current guarantees for every board. Use the actual datasheet conditions and board measurements, recording the supply measurement point, CPU clock, RF power, peripherals, memory retention and sleep mode. Account separately for USB adapters, LEDs, sensors and regulators.

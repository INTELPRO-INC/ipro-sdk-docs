快速開始

本指南將帶您完成 IPRO SDK Release 套件的安裝設定，並建構您的第一個應用程式。

Release SDK 說明：原始碼包未附燒錄工具（IntelProCube v0.6.3 命令列工具需另行取得）、板級測試腳本 board_test.sh 或 VS Code 擴充套件；序列埠監看工具 tools/serial_monitor.py 自 V2.1.0 起隨附。Windows 工具可參考安裝與更新章節，依元件版本另行安裝。

Online Installer 3.4.0 依元件清單下載；固定版 3.3.0 安裝包內含 SDK 1.2.1。元件清單目前仍選用 SDK 1.2.1，不會安裝 V2.1.0。V2.1.0 請由 GitHub Release 下載，並明確切換至解壓後的新目錄。安裝與版本選擇

SDK V2.1.0

下載 IPRO-SDK-V2.1.0（2026-10-15）：Release 提供 IPRO-SDK-V2.1.0.tar.gz 與 .sha256 校驗檔，原始碼亦位於 GitHub 儲存庫的 main 分支。套件含 34 個 IPRO7 應用（IPRO7 EVB、IPRO7AI EVK、IPRO7AI Reef EVK）；請以各範例隨附的板型設定建置。

本版新增：Zephyr RTOS 支援（見 Zephyr RTOS）；六個應用 ipro7ai_reef_demo、ipro7ai_evk_launcher、ipro7ai_evk_person_detect、ipro7ai_evk_rps、ipro_ai_link、ipro7_uvc_cam；以及 tools/serial_monitor.py、tools/zephyr/ 與 tools/create_ota.py。本版未包含 Matter、FreeRTOS 應用的 Thread（Thread 僅於 Zephyr 下提供）與模型轉換工具。

IPRO6S：V2.1.0 不支援 IPRO6S，未附 IPRO6S 應用與 IPRO6S BLE Controller 函式庫。IPRO6S 開發（BR/EDR、晶片內建 Wi-Fi 6、IPRO6S EVB）請使用 V2.0.1。

將 IPRO-SDK-V2.1.0.tar.gz 解壓至新目錄並核對 VERSION.txt。工具鏈需另行取得；本版 README 指定 GCC 14。套件清單中的 Windows GCC 13.1.1 相容宣告對應 SDK 1.2.1，不能直接視為 2.1.0 的相容保證。

系統需求

開始之前，請確保您的開發環境符合以下需求：

硬體需求

  • IPRO7 開發板：IPRO7 EVB、IPRO7AI EVK 或 IPRO7AI Reef EVK
  • USB 連接線（用於燒錄與序列埠通訊）
IPRO7AI Reef EVK：板上為 2 MB Flash，燒錄時使用 2 MB 分割表（例如 partition_cfg_2M.toml，以各應用 README 指定者為準）；上電前須插上 JP1 跳線。多數應用以 DEFCONFIG=defconfig_reef* 選用 Reef 設定，或直接附 Reef 的 .config（例如 ipro7ai_reef_demo）。

軟體需求

  • 作業系統：Linux（Ubuntu 20.04+ 建議）或 macOS
  • 工具鏈：RISC-V GCC 交叉編譯器（/opt/toolchain/riscv_ipro7/bin/riscv64-unknown-elf-*）
  • 建構工具：CMake 3.19+, Ninja, Make
  • Python：Python 3.8+（用於開發工具與腳本）
  • tar：解壓縮 Release SDK 套件
  • Zephyr（選用）：Python 3.10+、CMake 3.20+、Ninja、git、dtc，詳見 Zephyr RTOS
安裝基本工具（Ubuntu/Debian） 
# 安裝建構工具
sudo apt update
sudo apt install -y cmake ninja-build python3 python3-pip git

# 驗證安裝
cmake --version
ninja --version
python3 --version
安裝基本工具（macOS） 
# 使用 Homebrew 安裝
brew install cmake ninja python3 git

# 驗證安裝
cmake --version
ninja --version
python3 --version

安裝設定

1. 解壓縮 Release SDK 套件

注意：此為 Release 版本的 SDK 套件，無需透過 Git 取得原始碼。請從 GitHub Release 下載套件與 .sha256 校驗檔，校驗後解壓縮即可。
解壓縮 Release SDK 
# 校驗並解壓縮 Release SDK 套件（Linux 可用 sha256sum -c）
shasum -a 256 -c IPRO-SDK-V2.1.0.tar.gz.sha256
tar xzf IPRO-SDK-V2.1.0.tar.gz

# 進入已解壓縮的交付包目錄
cd IPRO-SDK-V2.1.0
cat VERSION.txt

2. 設定工具鏈

IPRO SDK 使用 RISC-V 交叉編譯器。預設路徑為 /opt/toolchain/riscv_ipro7/。

驗證工具鏈 
# 確認工具鏈存在
ls /opt/toolchain/riscv_ipro7/bin/

# 應該看到類似這些檔案：
# riscv64-unknown-elf-gcc
# riscv64-unknown-elf-g++
# riscv64-unknown-elf-objcopy
# ...

# 驗證編譯器可以執行
/opt/toolchain/riscv_ipro7/bin/riscv64-unknown-elf-gcc --version
注意：如果您的工具鏈位於不同路徑，請在建構時指定 CROSS_COMPILE 參數，例如：CROSS_COMPILE=/your/path/bin/riscv64-unknown-elf-。

快速開始建構

FreeRTOS 是 SDK 的主要開發路徑，V2.1.0 的 34 個應用皆以 FreeRTOS 建構。

使用 Make 建構（推薦）

Make 建構 
# 建構 BLE Remote 應用
make -C apps/bluetooth/ble/ipro_ble_remote

# 建構 LE Audio Headset 應用
make -C apps/bluetooth/le_audio/ipro_le_audio_headset

# 建構 IPRO7 Demo 應用
make -C apps/platform/ipro7_demo

# 建構 IPRO7AI Reef EVK 示範
make -C apps/platform/ipro7ai_reef_demo

# 以 DEFCONFIG 選用替代設定（輸出至 build_<name>/）
make -C apps/multimedia/ipro7_uvc_cam DEFCONFIG=defconfig_reef_ov5640

# 清除建構
make -C apps/bluetooth/ble/ipro_ble_remote clean

使用建構腳本

FreeRTOS 建構腳本 
# 列出所有可建構的專案
./build_freertos.sh -l

# 建構 BLE Remote 應用
./build_freertos.sh ipro_ble_remote build

# 建構 IPRO7 Demo 應用
./build_freertos.sh ipro7_demo build

手動 CMake 建構

CMake 建構指令 
# 設定專案（巢狀路徑的應用必須指定 CONFIG_APP_CATEGORY）
cmake -S . -B apps/bluetooth/ble/ipro_ble_remote/build \
    -G "Ninja" \
    -DIPRO_SDK_BASE=$(pwd) \
    -DCONFIG_BUILD_PORJECT=ipro_ble_remote \
    -DCONFIG_APP_CATEGORY=bluetooth/ble \
    -DCMAKE_PREFIX_PATH=$(pwd)/cmake \
    -DCUSTOM_CONFIG_DIR=$(pwd)/apps/bluetooth/ble/ipro_ble_remote \
    -DCONFIG_APPS=1 \
    -DCROSS_COMPILE=/opt/toolchain/riscv_ipro7/bin/riscv64-unknown-elf-

# 執行建構
cmake --build apps/bluetooth/ble/ipro_ble_remote/build

Zephyr RTOS 快速開始

V2.1.0 起，SDK 同時是 Zephyr v4.4.0 模組（zephyr/module.yml），根目錄的 west.yml 使其成為 west manifest 儲存庫。支援板型為 ipro7_evb（IPRO7 EVB）與 ipro7ai_evk（IPRO7AI EVK）；本版沒有 IPRO7AI Reef EVK 的 Zephyr 板型定義。

Zephyr 建構與燒錄 
tools/zephyr/bootstrap.sh          # 在 zephyr-workspace/ 建立 west 工作區
source zephyr-workspace/env.sh     # ZEPHYR_BASE、CROSS_COMPILE、west
cd zephyr-workspace
west build -b ipro7_evb zephyr/samples/hello_world
west build -b ipro7_evb ../zephyr/samples/periph_smoke -d build/smoke
west flash                         # IntelProCube 命令列工具：$IPRO_FLASH_TOOL 或 PATH

首次執行 bootstrap 會從 GitHub 下載 Zephyr v4.4.0 與 west.yml 所列模組，需要 Python 3.10+、CMake 3.20+、Ninja、git、dtc 與 IPRO RISC-V 工具鏈（/opt/toolchain/riscv_ipro7，可用 IPRO_TOOLCHAIN 覆寫）。Zephyr 主控台為 UART0 2,000,000 baud。本版 Zephyr 未提供低功耗模式，以及顯示、攝影機、音訊 codec、USB、SD host、Ethernet 與 NPU 驅動，這些功能請使用 FreeRTOS。完整說明請見 Zephyr RTOS。

Kconfig 配置系統

SDK 使用 Linux kernel 風格的 Kconfig 系統管理專案配置。每個應用擁有自己的 .config 檔案，建構時自動生成 generated/autoconf.h 標頭檔。

配置檔案結構

  • 根配置：Kconfig - 彙總所有選項定義（透過 source 引入下層 Kconfig）
  • 各層選項定義：bsp/Kconfig 與 components/Kconfig - BSP 與中介軟體元件的選項定義
  • 應用配置：apps/<category>/<project>/.config - 每個應用的完整建構配置，建構時據此生成 generated/autoconf.h
  • 替代設定：部分應用另附 defconfig_<name> 或 config_<board>，以 make DEFCONFIG=defconfig_<name>（輸出至 build_<name>/）或 make BOARD=<board> 選用；IPRO7AI Reef EVK 多以 defconfig_reef* 選用

常用配置選項

.config 範例 
# SoC 選擇
CONFIG_IPRO7=y
CONFIG_CPU_ID="intelpro_ipro7"

# RTOS 選擇
CONFIG_FREERTOS_SUPPORT=y

# 無線功能
CONFIG_BLUETOOTH_LE_ENABLE=y

# BLE Controller prebuilt 函式庫變體選擇
CONFIG_BT_CTLR_IPRO=y
CONFIG_BT_HOST_IPRO_V44=y
CONFIG_IPRO_BLE_CTLR_LIB="link2"
CONFIG_IPRO_BLE_CTLR_FEATURE="bt52"
CONFIG_IPRO_BLE_CTLR_CFG_DBG=n
CONFIG_BT_CONN=2
CONFIG_EM_SIZE=32

# 元件啟用
CONFIG_COMPONENTS_LWIP_ENABLE=y
CONFIG_COMPONENTS_MBEDTLS_ENABLE=y
提示：CONFIG_CPU_ID 必須在 .config 中正確設定，工具鏈才能偵測對應的架構旗標。cmake/toolchain.cmake 會自動偵測 vendor GCC 與標準 GCC 並調整編譯選項。

燒錄韌體

Release SDK 說明：燒錄工具與自動化測試腳本 board_test.sh 未包含在此 Release SDK 套件中。燒錄使用 IntelProCube v0.6.3 的命令列工具（ipro_iot_tool.exe、ipro_iot_tool_macos 或 ipro_iot_tool_linux），請聯絡 INTELPRO 另行取得。

IntelProCube 命令列燒錄

燒錄指令 
# IPRO7 EVB（--chip-variant IPRO7）
ipro_iot_tool_macos --chipname ipro7 --chip-variant IPRO7 --port /dev/cu.usbserial-XXXX \
    --baudrate 2000000 --firmware apps/bluetooth/ble/ipro_ble_remote/build/build_out/ipro_ble_remote_IPRO7.bin

# IPRO7AI Reef EVK（--chip-variant IPRO7AI；在 IntelProCube 目錄下執行，使用 2 MB 分割表）
ipro_iot_tool_macos --chipname ipro7 --chip-variant IPRO7AI --port /dev/cu.usbserial-XXXX \
    --baudrate 921600 --pt chips/ipro7/partition/partition_cfg_2M.toml \
    --firmware <SDK>/apps/platform/ipro7ai_reef_demo/build/build_out/ipro7ai_reef_demo_IPRO7.bin
  • 工具沒有 --flash-pin 選項：--chip-variant IPRO7 對應 flash_pin 0x2，IPRO7AI 對應 0x9（IPRO7AI EVK 與 Reef），並寫入 IntelProCube 目錄下的 chips/ipro7/eflash_loader/eflash_loader_cfg.ini。
  • 燒錄失敗時工具仍回傳 0，請以輸出中的 [All Success] 判斷結果。
  • ./build_freertos.sh <project> flash 會呼叫此工具：設定 IPRO_FLASH_TOOL 指向工具，或將其目錄加入 PATH。

序列埠提示（一般知識）

macOS 注意：序列埠必須使用 /dev/cu.* 裝置，而不是 /dev/tty.*。tty.* 裝置會等待 DCD 訊號而造成阻塞。Linux 使用者請使用 /dev/ttyUSB0 或類似裝置。

序列埠監看

V2.1.0 隨附 tools/serial_monitor.py（以 Python 標準函式庫 termios 實作，不需 pyserial），build_freertos.sh 的 monitor／test 動作即使用此腳本。也可直接執行：

serial_monitor.py 
# 監看主控台（--baud 預設 115200；請依應用的 CONFIG_PLATFORM_UART_BAUDRATE 設定）
python3 tools/serial_monitor.py /dev/cu.usbserial-XXXX --baud 115200 --timeout 60

# 送出指令後監看，並等待指定輸出（regex）
python3 tools/serial_monitor.py /dev/cu.usbserial-XXXX --send reboot --wait-for "ALL TESTS PASSED|SOME TESTS FAILED"

主控台鮑率由各應用 .config 的 CONFIG_PLATFORM_UART_BAUDRATE 決定（未設定為 115200）：多數應用為 115200，ipro7ai_evk_demo、ipro7ai_evk_launcher、ipro7ai_evk_rps、ipro_meeting_poc、ipro7_uvc_cam 與 ipro_epd_el036 為 921600；Reef 的主控台在 U6 接頭；Zephyr 映像檔為 UART0 2,000,000。macOS 使用 /dev/cu.*。燒錄前停止監看以釋放序列埠。也可使用 Extension 的 IPRO: Serial Monitor 或其他序列埠終端工具。

板級測試

SDK 已包含 apps/test/ipro_unit_test/，測試 HAL 與共用元件，並在主控台輸出 ALL TESTS PASSED 或 SOME TESTS FAILED。

make -C apps/test/ipro_unit_test

# 建構＋燒錄＋監看並判讀結果（需 IntelProCube 命令列工具）
./build_freertos.sh test ipro_unit_test -p /dev/cu.usbserial-XXXX

test 動作依序建構、燒錄，再以隨附的 tools/serial_monitor.py 等待測試結果；結束碼 0 為通過、1 為失敗、2 為逾時。燒錄工具需另行取得，tools/board_test.sh 未隨附。

序列埠除錯

大多數應用支援透過序列埠 CLI 進行即時除錯。連接序列埠後可使用以下指令：

  • reboot - 正常重啟
  • reboot_dl - 進入下載模式（用於重新燒錄）
提示：VS Code 擴充套件需另行安裝。請依Extension 指南設定 SDK、工具鏈與除錯工具路徑。

疑難排解

macOS 序列埠問題（一般知識）

注意： V2.1.0 隨附 tools/serial_monitor.py，也可使用外部序列埠終端工具。
問題 解決方案
序列埠連線無回應或阻塞 使用 /dev/cu.* 而非 /dev/tty.*。tty.* 會等待 DCD 訊號。
cat 指令無輸出 cat 在 macOS 上對序列埠有緩衝問題，請使用 tools/serial_monitor.py 或專門的序列埠工具（如 minicom、screen 或 picocom）。
序列埠顯示 "Resource busy" 確認沒有其他程式佔用序列埠（如 stty、其他序列埠監看工具），必要時重新插拔 USB。

工具鏈問題

問題 解決方案
找不到工具鏈 確認 /opt/toolchain/riscv_ipro7/bin/ 存在且包含 riscv64-unknown-elf-gcc。
工具鏈路徑不同 設定 CROSS_COMPILE 環境變數指向正確路徑。

建構錯誤

問題 解決方案
架構旗標偵測失敗 確認 .config 檔案中 CONFIG_CPU_ID 已正確設定為 "intelpro_ipro7"。
CMake 配置錯誤 嘗試清除建構目錄：make -C apps/<project> clean，然後重新建構。
隨附的 tools/cmake/ 在 macOS 上無法執行 隨附的 CMake 為 Linux x86-64 版本。請另行安裝適合主機作業系統的 CMake 3.19+（Zephyr 需 3.20+），並加入 PATH。

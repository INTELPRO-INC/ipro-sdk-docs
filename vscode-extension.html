IPRO SDK VS Code Extension

⚠ Release SDK 注意事項：此擴充套件未包含在 Release SDK v1.0.1 中，以下內容僅供參考。擴充套件（.vsix）及其呼叫的燒錄工具（tools/ipro_iot_tool_lite/）與串口監控工具（tools/serial_monitor.py）請聯絡原廠取得。

專為 IPRO SDK 設計的 VS Code 擴充套件，在 Windows、macOS、Linux 上提供建構、燒錄、序列埠監控、Kconfig 設定與記憶體分析等一站式開發體驗。

概覽

IPRO SDK Extension（v2.1.0）是單一擴充套件，開啟含有 build_freertos.sh 的 SDK 工作區即自動啟用，無需額外安裝其他配套套件。

核心能力

  • 專案總覽與切換（Projects / Device / Quick Actions 三個側邊欄視圖）
  • 一鍵 Build / Clean / Flash / Serial Monitor
  • Menuconfig 設定編輯（圖形介面 + 終端機 menuconfig）
  • Memory Map 視覺化與建置記憶體分析
  • Build Profiles（debug / release / size）與批次建構

系統需求

項目 需求
VS Code 1.102 或以上
作業系統 Windows / macOS / Linux
建構工具 CMake（≥ 3.20）+ Make 或 Ninja
工具鏈 RISC-V 交叉編譯器（預設 /opt/toolchain/riscv_ipro7/bin/riscv64-unknown-elf-）
Python 3 燒錄前自動進入 download mode 與終端機 menuconfig（pip install kconfiglib）需要

功能特色

三視圖側邊欄

Projects 視圖自動掃描 SDK 內所有專案，支援 Pin 置頂與最近使用清單；Device 視圖顯示序列埠、SDK 與工具鏈版本；Quick Actions 提供一鍵操作。

一鍵建構與燒錄

Build / Clean / Flash / Serial Monitor 皆可從 Quick Actions 或快捷鍵觸發，狀態列即時顯示建置結果與耗時。

Menuconfig 整合

圖形化 .config 編輯器、終端機 menuconfig、Load Defconfig 與直接開啟 .config 四種 Kconfig 編輯方式。

Memory Map 視覺化

Flash / RAM 環圈圖、區段堆疊條、元件 treemap 與建置差異比較，可匯出 CSV 或 Markdown 報告。

Build Profiles

debug（-O0 -g）/ release（-O2）/ size（-Os）三種建置設定一鍵切換，並支援多專案 Batch Build。

序列埠自動偵測

每 3 秒輪詢 USB 序列裝置，插拔即時更新狀態列與 Device 視圖；macOS 自動列出 /dev/cu.usb* 裝置。

此外，建置成功後會自動偵測 compile_commands.json 並設定 C/C++ 擴充套件的 IntelliSense；內建 problem matchers（$ipro-gcc-error、$ipro-gcc-warning、$ipro-linker、$ipro-cmake）讓編譯與連結錯誤可直接點擊跳轉到原始碼。

安裝指南

1. 安裝擴充套件

  1. 向原廠取得 ipro-sdk-extension-2.1.0.vsix
  2. 開啟 VS Code 的 Extensions 面板（Ctrl+Shift+X），將 .vsix 檔案拖曳進面板；或使用命令列安裝：
命令列安裝 
code --install-extension ipro-sdk-extension-2.1.0.vsix

2. 準備工具鏈

安裝 RISC-V 工具鏈（macOS / Linux） 
# 下載並解壓工具鏈到 /opt/toolchain/riscv_ipro7/
# 擴充套件預設使用此路徑，無需額外設定

# 驗證安裝
/opt/toolchain/riscv_ipro7/bin/riscv64-unknown-elf-gcc --version

若工具鏈安裝在其他位置，可在設定中以 devtool.toolchainPath 覆寫交叉編譯器前綴（例如 /your/path/bin/riscv64-unknown-elf-）。

3. 開啟 SDK 工作區

  1. 選擇 File → Open Folder...，開啟 IPRO SDK 根目錄
  2. 偵測到 build_freertos.sh 後擴充套件自動啟用，左側活動列出現 IPRO SDK 圖示
  3. 若 SDK 不在工作區根目錄，可執行 F1 → IPRO SDK: Set SDK Root 手動指定

燒錄工具自動定位

燒錄使用 SDK 內建的 tools/ipro_iot_tool_lite/ipro_iot_tool_lite（Windows 為 .exe），擴充套件會自動從 SDK 根目錄定位，無需另行下載或設定路徑。

開發流程

1. 選擇專案

  1. 點擊左側活動列的 IPRO SDK 圖示
  2. 在 Projects 視圖中點選專案（支援右鍵 Pin 置頂，最近使用的 5 個專案會自動列在置頂專案下方）
  3. 專案描述會顯示建置狀態與時間（例如 IPRO7 ✓ 2m ago）

2. 設定（可選）

  • Menuconfig：圖形化編輯專案 .config
  • Load Defconfig：載入預設設定檔
  • Open .config：直接以文字編輯器開啟設定檔
  • Build Profile：以 IPRO SDK: Select Build Profile 切換 debug / release / size，目前 profile 顯示於狀態列

3. 建構

在 Quick Actions 點擊 Build，或在編輯器中按 Ctrl+Shift+B。建構產生器預設為 make，可透過 devtool.generator 設定切換為 ninja。

Build 輸出範例 
[Build] [1/45] Building C object ...
[Build] [45/45] Linking C executable ...
Build OK (12.3s)

建構完成後，韌體檔案位於（apps/ 採 <category>/<name> 巢狀結構）：

apps/<category>/<name>/build/build_out/<name>_IPRO7.bin

建置成功後擴充套件會自動套用 compile_commands.json 到 C/C++ IntelliSense，並自動更新 Memory Map 面板；編譯錯誤與警告可在 Problems 面板點擊跳轉。

4. 批次建構

執行 IPRO SDK: Batch Build 可勾選多個專案依序建構，並顯示整體進度，適合一次驗證多個應用。

其他輔助指令

  • IPRO SDK: New Project：從範本建立新專案
  • IPRO SDK: Dashboard：開啟專案總覽面板，顯示建置狀態與韌體大小

燒錄與監控

燒錄

  1. 以 USB 連接開發板
  2. 在 Quick Actions 點擊 Flash，或在編輯器中按 Ctrl+Shift+F
  3. 若未設定序列埠，擴充套件會自動列出偵測到的裝置供選擇（macOS 列出 /dev/cu.usb*，Linux 列出 /dev/ttyUSB*、/dev/ttyACM*，Windows 列出 COM 埠）
  4. 擴充套件先透過 tools/serial_monitor.py 送出 reboot_dl 讓開發板進入 download mode，再呼叫 ipro_iot_tool_lite 燒錄

設定參數

設定 說明 預設值
devtool.serialPort 燒錄與監控使用的序列埠 空（自動偵測 + QuickPick 選擇）
devtool.baudRate 序列埠傳輸速率 921600
devtool.flashPin 傳給 ipro_iot_tool_lite 的 flash pin 參數 0x02
devtool.partitionTable 分割表檔案路徑（選填，對應 --pt 參數） 空
devtool.autoDetectPort USB 裝置插拔時自動偵測序列埠 true

晶片型號（如 ipro7）由專案設定自動帶入，無需手動指定。

燒錄進度

燒錄進度顯示於 VS Code 右下角通知列，依序經過四個階段：

  1. boot / partition：寫入開機程式與分割表
  2. 韌體寫入：主韌體燒錄，顯示即時百分比
  3. 驗證：韌體校驗
  4. 完成：顯示 Flash complete 通知

序列埠監控

在 Quick Actions 點擊 Monitor，或在編輯器中按 Ctrl+Shift+S，擴充套件會開啟整合終端機並以 SDK 內建的 tools/serial_monitor.py 連接開發板（自動送出 reboot 重新啟動以擷取完整開機日誌）。若 SDK 中沒有該工具，會改用系統內建指令（macOS / Linux 為 screen）連接。

macOS 序列埠

在 macOS 上必須使用 /dev/cu.* 裝置（例如 /dev/cu.usbserial-XXXX，實際名稱依裝置而定），而非 /dev/tty.*。tty.* 裝置會等待 DCD 信號導致掛住。擴充套件的自動偵測已只列出 cu.* 裝置。

Memory Map 視覺化

執行 IPRO SDK: Memory Map（或在 Quick Actions 點擊 Memory Map）可開啟記憶體分析面板，解析建置產生的 .map 檔案：

  • Flash / RAM 環圈圖：以彩色區段顯示各 section 占比，中央顯示使用率百分比
  • 區段堆疊條：每個記憶體區域顯示 .text、.rodata、.data、.bss 等 section 的分布；使用率以顏色標示（綠 <70%、黃 70–85%、紅 >85%）
  • 元件表格：可排序、可搜尋，展開列可查看單一元件各 section 的占用明細
  • 元件 treemap：以面積比例顯示前 20 大元件
  • 建置比較：自動與前一次建置比較，以紅綠增減量（±KB）標示差異
  • 匯出：一鍵匯出 CSV（元件明細）或 Markdown（完整報告）

當 Flash 或 RAM 使用率超過門檻（devtool.memoryThresholdFlash / devtool.memoryThresholdRam，預設 85%）時，擴充套件會主動跳出警告通知。建置成功後面板會自動更新。

IPRO7 的記憶體配置可參考：Flash 1 MB、PSRAM 8 MB、OCRAM 256 KB。詳見 硬體規格。

常見問題

Q1: 側邊欄顯示「No IPRO SDK detected」

問題：擴充套件找不到 SDK。

解決方法：

  1. 確認開啟的工作區包含 SDK 根目錄的 build_freertos.sh
  2. 或執行 F1 → IPRO SDK: Set SDK Root 手動指定 SDK 路徑（寫入 devtool.sdkRoot 設定）

Q2: 找不到工具鏈

問題：建構失敗，找不到 riscv64-unknown-elf-gcc。

解決方法：

  1. 確認工具鏈已安裝在預設路徑 /opt/toolchain/riscv_ipro7/bin/
  2. 若安裝在其他位置，在設定中以 devtool.toolchainPath 指定交叉編譯器前綴（例如 /your/path/bin/riscv64-unknown-elf-）

Q3: 序列埠未列出或連接失敗

問題：燒錄或監控時找不到序列埠，或連線失敗。

解決方法：

  1. 確認 USB 線已連接且驅動正常，執行 IPRO SDK: Select Serial Port 重新選擇
  2. 關閉其他占用序列埠的程式（終端機、其他監控工具）
  3. macOS 上確認選擇的是 /dev/cu.* 裝置
  4. 確認 devtool.autoDetectPort 為開啟狀態，插拔 USB 後等待約 3 秒讓自動偵測更新

Q4: 燒錄時顯示「Binary not found」

問題：韌體檔案不存在。

解決方法：

  1. 先執行 Build（Ctrl+Shift+B）
  2. 確認 apps/<category>/<name>/build/build_out/ 目錄下有 <name>_IPRO7.bin

Q5: 顯示「Flash tool (ipro_iot_tool_lite) not found in SDK tools/」

問題：SDK 內找不到燒錄工具。

解決方法：

  1. 確認 tools/ipro_iot_tool_lite/ipro_iot_tool_lite 存在於 SDK 根目錄下
  2. 此工具未包含在 Release SDK v1.0.1 中，請聯絡原廠取得後放置於上述路徑

命令列工具整合

除了 VS Code Extension 的圖形介面外，也可以直接使用命令列工具進行開發。apps/ 目錄採 <category>/<name> 巢狀結構，make -C 需使用完整路徑；可用 ./build_freertos.sh -l 列出所有專案。

建構

命令列建構 
# 列出所有專案
./build_freertos.sh -l

# 推薦的建構方式（完整巢狀路徑）
make -C apps/bluetooth/ble/ipro_ble_remote

# 或使用 build_freertos.sh（接受專案名稱）
./build_freertos.sh ipro_ble_remote build

# 清除編譯
make -C apps/bluetooth/ble/ipro_ble_remote clean

燒錄工具

SDK 內建燒錄工具位於 tools/ipro_iot_tool_lite/ipro_iot_tool_lite（非 OpenOCD）：

命令列燒錄（macOS / Linux） 
# 序列埠名稱依實際裝置而定（macOS 使用 /dev/cu.*）
tools/ipro_iot_tool_lite/ipro_iot_tool_lite \
    --chipname ipro7 \
    --port /dev/cu.usbserial-XXXX \
    --firmware apps/bluetooth/ble/ipro_ble_remote/build/build_out/ipro_ble_remote_IPRO7.bin \
    --baudrate 921600 --flash-pin 0x02

macOS 序列埠

在 macOS 上必須使用 /dev/cu.usbserial-XXXX（cu.*，實際名稱依裝置而定），而非 /dev/tty.*。tty.* 裝置會等待 DCD 信號導致掛住。

自動化測試

使用 board_test.sh 進行完整的建構、燒錄、序列埠監控和測試結果解析：

自動化板級測試 
# 完整測試流程（建構 + 燒錄 + 監控 + 解析結果）
tools/board_test.sh --project apps/test/ipro_unit_test

# 結束代碼：0=通過, 1=失敗, 2=超時

快捷鍵

擴充套件提供三個專屬快捷鍵（需編輯器處於聚焦狀態）：

功能 快捷鍵 說明
Build Ctrl+Shift+B 建構目前選擇的專案
Flash Ctrl+Shift+F 燒錄韌體到開發板
Serial Monitor Ctrl+Shift+S 開啟序列埠監控
打開命令面板 Ctrl+Shift+P 或 F1 VS Code 通用（搜尋「IPRO SDK」可列出所有指令）
Extensions 面板 Ctrl+Shift+X VS Code 通用

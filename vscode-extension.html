IPRO SDK VS Code Extension

在 VS Code 完成環境設定、建構、燒錄與監看，並管理獨立的 SDK 與 Extension 更新。

Extension 概覽

IPRO SDK Extension 3.3.0（識別碼 ipro.ipro-sdk-extension）將 FreeRTOS 專案探索、CMake 建構、IntelProCube 燒錄、序列埠主控台與記憶體分析整合至 VS Code。Windows 首次使用可透過完整安裝包取得所需工具。

本頁說明 Extension 3.3.0（需 VS Code 1.102+）。SDK V2.1.0 與 Online Installer 3.4.0 獨立管理版本；目前套件清單仍選用 SDK 1.2.1。V2.1.0 請由 GitHub Release 下載，匯入解壓後資料夾並確認工具鏈相容性。

Windows 安裝與更新指南

功能介紹

功能用途
Projects / Target分類探索專案、Pin 與最近使用；顯示目前專案、Profile、UART、Probe 與工具狀態。
Control Center集中顯示連線、主控台鮑率與操作狀態，提供 Build／Flash／Monitor 及元件更新入口。
Build / Batch BuildCMake 配置與 Make／Ninja 建構、debug／release／size、Problems 錯誤跳轉與 compile_commands.json 整合。
MenuconfigExtension 內建圖形化 Kconfig 編輯器，可載入 defconfig 或直接編輯 .config；圖形編輯器不需 kconfiglib。
Flash / Monitor使用 IntelProCube 燒錄；Extension 內建 serialport 主控台可在 Windows 運作，監看與燒錄鮑率分開。
Analysis / Debug toolsMemory Map、Decode Crash Report、Pin Function Lookup，以及需相容 CCI 連線的 Register Explorer。

安裝與設定

  1. 首次 Windows 安裝使用完整 EXE；已有工具環境則安裝 ipro-sdk-extension-win32-x64-3.3.0.vsix 或對應 ARM64 版本。
  2. 透過 Extensions → … → Install from VSIX… 安裝後，執行 Developer: Reload Window。
  3. File → Open Folder… 開啟 SDK 根目錄；根目錄須包含 CMakeLists.txt、apps 與 bsp。確認來源後允許 Workspace Trust。
  4. 使用 IPRO Setup: Set SDK Root 與 IPRO Setup: Run Diagnostics 核對環境。Windows 完整安裝包會設定 ipro.* 路徑。
code --install-extension .\ipro-sdk-extension-win32-x64-3.3.0.vsix
完整工具設定範例

3.x 設定使用 ipro.* 命名空間。舊文件中的 devtool.* 與 IPRO SDK: 命令名稱請改用本頁設定與命令表。

控制中心

按 F1 → IPRO: Open Control Center。控制中心顯示目前 SDK／專案、UART、設定與實際 Monitor 鮑率，並依工作狀態啟用操作。開啟面板本身不會燒錄或重設開發板。

支援明暗／高對比主題、窄視窗排版與鍵盤焦點；動畫可暫停，並遵循降低動態效果的偏好。

第一次建構

  1. 執行 IPRO: Go to Project…，選擇 platform 分類的 ipro7_demo。
  2. 執行 IPRO Config: Select Build Profile，選擇 debug、release 或 size。
  3. 執行 IPRO Setup: Run Diagnostics，核對 SDK、編譯器、CMake、Ninja 與 Python 的實際路徑。
  4. 執行 IPRO: Build，在 Terminal 觀察建構結果；錯誤可由 Problems 跳到來源位置。
  5. 確認 BIN 與 ELF 產生。SDK 或工具路徑更動後，Clean 並重新 Build，避免沿用舊快取。
apps/platform/ipro7_demo/build/build_out/ipro7_demo_IPRO7.bin

安裝器預設使用 Ninja；Extension 的 ipro.generator 亦可設定 auto、make 或 ninja。IPRO: Batch Build 可一次建構多個選定專案。

燒錄、UART 與 Monitor

  1. 以 IPRO Setup: Select Flash Tool 選擇 IntelProCube，或設定 ipro.flashToolPath 為 C:\IPRO\IntelProCube。
  2. 接上開發板，執行 IPRO: Select Serial Port，選擇 Probe 的 UART 埠；CCI 埠供暫存器存取，不用於主控台／燒錄。
  3. IPRO Config: Configure Flash… 核對晶片配置、Flash target、分割表與鮑率。晶片配置必須符合實際板子，不要直接套用截圖中的值。
  4. 執行 IPRO: Flash，確認燒錄工具的驗證與成功訊息。Extension 會先釋放自己的 Monitor 連線；其他程式占用序列埠時仍需先關閉。
  5. 用 IPRO Config: Set Monitor Baud Rate 設定符合韌體的主控台速率，再執行 IPRO: Serial Monitor。修改速率後關閉並重開 Monitor，或使用提供的重新連線操作。
設定意義
ipro.baudRate燒錄速率；預設 921600
ipro.monitorBaudRate主控台速率；預設 115200，需與韌體一致
ipro.chipVariant板端燒錄配置，並非建構 Profile
Extension 3.2.0 起使用內建 serialport，Windows Monitor 不依賴 SDK 的 POSIX serial_monitor.py，也不會在開啟時自動 reboot。要重啟板子可執行 IPRO: Reset Board，或在支援的韌體主控台輸入 reboot。

記憶體與除錯工具

建構後執行 IPRO Analyse: Memory Map，檢視各記憶體區域、元件用量與前後建構差異，並可匯出 CSV／Markdown。容量判斷仍需對照 linker 輸出與實際分割表。

IPRO Analyse: Decode Crash Report 可將例外回溯轉為來源位置；IPRO Debug: Pin Function Lookup 查詢腳位。Register Explorer 需相容 Probe、CCI 連線與正確的板端設定。Extension 3.3.0 未提供一般 GDB debug adapter；安装 OpenOCD 不等於可直接按 F5 完成來源碼除錯。

元件獨立更新

Extension 3.3.0 提供 F1 → IPRO Setup: Update Components，也可從控制中心進入。

來源行為
Extension VSIX選取對應 VSIX，安裝後 Reload Window；不更新 SDK 或工具。
SDK ZIP選取 ZIP，可輸入 INTELPRO 提供的 SHA-256；解壓並驗證 SDK 結構。
SDK Folder選取已解壓且含 CMakeLists.txt、apps、bsp 的根目錄；.tar.gz／.7z 先自行解壓。
SDK Git使用有權限存取的 HTTPS／SSH 倉庫及 branch／tag 建立快照，記錄 commit；SSH 信任與認證需事先完成。
  1. 選擇來源後，指定版本儲存父目錄及尚未存在的新版本名稱。
  2. 確認來源與目的地後開始匯入；Output → IPRO SDK 顯示進度與紀錄。
  3. 完成後可在新視窗開啟。SDK Root、工具鏈與原視窗不會自動切換。
  4. 執行 Diagnostics 與官方範例 Build，再逐項遷移個人修改；保留舊 SDK 以便回復。
C:\IPRO\sdk\<version-name>\
  sdk\          SDK root: CMakeLists.txt, apps, bsp
  update.json   Source, timestamp, checksum / Git commit
  update.log    Update result

VS Code 匯入的根目錄在新版本目錄內的 sdk\；EXE SDK-only 則直接使用所選新目錄。失敗／取消時保留未完成目錄與紀錄；重試使用新名稱。Git 匯入是快照，不是後續可直接 pull 的工作樹；不支援 submodule、未解析的 LFS pointer 或符號連結，也不自動更新工具鏈。

常見問題

現象處理
找不到 IPRO 命令核對 VSIX 版本、Profile、Workspace Trust 與 SDK 根目錄；重新載入視窗。
SDK Root 切換未生效工作區／資料夾設定與開啟的 SDK 可優先於 User 設定；以 Diagnostics 實際路徑為準。
Monitor 亂碼或仍使用舊速率核對韌體主控台速率及 ipro.monitorBaudRate；關閉並重開 Monitor。
Probe 偵測成功但 CCI 不通USB 配對成功不代表板端 CCI 通訊完成；另行核對連接與板端設定。
找不到 Flash tool使用 IPRO Setup: Select Flash Tool，確認 IntelProCube 中有 ipro_iot_tool.exe。

IntelProCube 與命令列

完整包中的 C:\IPRO\IntelProCube\IProCube.exe 是圖形化工具；ipro_iot_tool.exe 提供命令列燒錄，ipro_ota_creator.exe 與 ipro_ota_update_tool.exe 用於 OTA 套件建立與更新。圖形介面操作手冊位於 IntelProCube\docs\USER_GUIDE.html。

& "C:\IPRO\IntelProCube\ipro_iot_tool.exe" --help

使用命令列前依該版 --help 與實際板子設定參數。Windows 原生開發可直接使用 Extension 的 CMake／Ninja 流程；SDK 的 build_freertos.sh 為 Bash 入口。

版本與交付範圍

3.3.0 新增元件獨立更新；3.2.4 引入控制中心；3.2.3 改善 Monitor／Flash 序列埠交接與 UART／CCI 選擇；3.2.2 提供獨立 Monitor 鮑率；3.2.1 加入 Windows 工具路徑固定設定；3.2.0 提供內建 serialport Monitor。

SDK 原始碼交付包、Extension VSIX 與完整 Windows 安裝包分開計版。SDK 包內沒有 VSIX，不代表 Windows 完整包沒有 Extension；請以取得的安裝包 manifest 與 Extensions 面板實際版本為準。

SDK V2.1.0

由 V2.1.0 Release 下載 IPRO-SDK-V2.1.0.tar.gz 及其 .sha256，解壓至新的 SDK 目錄。確認 VERSION.txt 顯示 V2.1.0，選取的根目錄包含 CMakeLists.txt、apps/ 與 bsp/。V2.1.0 的 FreeRTOS 應用僅支援 IPRO7；IPRO6S 開發請保留 V2.0.1。

Get-FileHash .\IPRO-SDK-V2.1.0.tar.gz -Algorithm SHA256
Get-Content .\IPRO-SDK-V2.1.0.tar.gz.sha256

比對下載的 checksum 與計算結果。Extension 3.3.0 可由 IPRO Setup: Update Components 匯入解壓後資料夾，或直接選擇該 SDK 根目錄；壓縮檔匯入入口接受 ZIP，.tar.gz 請先解壓。重新開啟新 SDK 並執行 IPRO Setup: Run Diagnostics。

SDK README 指定 GCC 14；目前 Windows 清單僅對 SDK 1.2.1 宣告 GCC 13.1.1 的相容組合，V2.1.0 請另行取得並驗證相容工具鏈。原生 Windows Make 時，project.build 在找不到未隨附的 tools/cmake_win-x86_64/ 時改用 PATH 上的 cmake；請確認 PATH 上的 CMake 版本，或明確傳入 CMAKE=。在完成新版本建置及板端驗證前，保留可用的 1.2.1 環境。

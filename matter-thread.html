Matter & Thread

交付狀態

IPRO SDK V2.1.0 未包含 Matter 協定堆疊與 Matter 應用。Thread 在 V2.1.0 只在 Zephyr RTOS 下提供：使用 Zephyr 的 OpenThread 與 IPRO7 的 IEEE 802.15.4 驅動；FreeRTOS 應用不含 Thread。本頁說明整合邊界，不代表此版本已通過 Matter／Thread 認證，也沒有可直接執行的 Matter build 命令。

架構概念

Matter 是以 IP 為基礎的應用層協定，可使用 Wi-Fi、Ethernet 或 Thread 作為網路傳輸，BLE 可用於配網。請參考 CSA Matter 官方說明；具備 BLE、TCP/IP 或 Thread 元件不等於已整合 Matter。

Matter over Thread

Thread 是低功耗 IPv6 mesh 網路。整合時需相容的 IEEE 802.15.4 無線端、Thread 堆疊及連到其他 IP 網路的 Border Router；請參考 Thread Group 官方說明。V2.1.0 在 Zephyr RTOS 下提供 OpenThread CLI 範例，但沒有 Border Router 或 Matter 範例，無法據以驗證 Matter over Thread 的完整路徑。

Wi-Fi／Ethernet 傳輸

IPRO7 無內建 Wi-Fi。V2.1.0 在 FreeRTOS 下提供以 IPRO6S 作為 SDIO 無線端的 IPRO7 端範例（ipro7_sdio_wifi，IPRO6S 端韌體不在 V2.1.0 內；IPRO7AI Reef EVK 則為 ipro7ai_reef_demo 的 defconfig_wifi_ipro6s 搭配 IPRO6S FIN 卡，FIN 卡韌體請洽 INTELPRO）、ATBM6162 模組探測程式（ipro_atbm_probe）及 Ethernet（ipro7_demo 的 EMAC），詳見網路開發。這些範例建立網路連線，尚未包含 Matter endpoint、配網或憑證管理。

OpenThread（Zephyr RTOS）

V2.1.0 的 Thread 只在 Zephyr RTOS 下提供：Zephyr 的 IEEE 802.15.4 驅動使用 IPRO7 的無線電，上層為 Zephyr 的 OpenThread。RF 驅動與 802.15.4 MAC 以預編譯函式庫連結（components/wireless/rf/ipro7_rf/lib/zephyr/、components/wireless/ieee802154/lib/zephyr/）。範例使用 Zephyr 的 samples/net/openthread/shell，加上 SDK 的 zephyr/samples/ieee802154_shell/ot.conf 與 app.overlay：

cd zephyr-workspace
west build -b ipro7_evb zephyr/samples/net/openthread/shell -d build/ot -- \
    -DEXTRA_CONF_FILE=<SDK>/zephyr/samples/ieee802154_shell/ot.conf \
    -DEXTRA_DTC_OVERLAY_FILE=<SDK>/zephyr/samples/ieee802154_shell/app.overlay

<SDK> 為 SDK 根目錄的絕對路徑。Zephyr 支援的板子為 ipro7_evb 與 ipro7ai_evk；工作區建立、燒錄與 Console 設定請見 Zephyr RTOS。FreeRTOS 應用不含 Thread；也不要將 SDK 中的 BLE Controller 函式庫視為 OpenThread 實作。

目前可用的參考範例

IP 連線可先以 FreeRTOS 的 ipro7_demo（Ethernet）、ipro7_sdio_wifi（IPRO6S SDIO 無線端）或 ipro7ai_reef_demo 的 defconfig_wifi_ipro6s（IPRO6S FIN 卡）驗證；Thread 以 Zephyr 的 OpenThread shell 範例驗證。V2.1.0 的 35 個 FreeRTOS 應用不含 Matter 或 Thread 應用。

AI 與網路應用

AI 範例使用 .inm 或 .tflite 模型。把推論結果送到網路服務需自行定義資料格式、緩衝與傳輸；V2.1.0 沒有 Matter NPU embedding 串流範例。

整合前需確認的設定

取得相容協定套件後，再確認工具鏈、RTOS 適配、Flash／RAM 預算、持久儲存、熵來源、憑證與 OTA 設計。不能只新增一個 Kconfig 選項就啟用未交付的堆疊；Thread 也只能在 Zephyr RTOS 下使用，無法在 FreeRTOS 應用中以設定選項開啟。

建議驗證順序

依序驗證板級驅動、無線／Ethernet 連線、IP 傳輸及安全儲存，再進行協定整合、配網、重啟恢復與互通性測試。產品支援版本及認證狀態須以實際整合成果確認。

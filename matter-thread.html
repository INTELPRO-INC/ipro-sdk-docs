Matter & Thread

交付狀態

IPRO SDK V2.0.1 未交付 Matter 或 OpenThread 協定堆疊與完整應用。本頁說明整合邊界，不代表此版本已通過 Matter／Thread 認證，也沒有可直接執行的 Matter build 命令。

架構概念

Matter 是以 IP 為基礎的應用層協定，可使用 Wi-Fi、Ethernet 或 Thread 作為網路傳輸，BLE 可用於配網。請參考 CSA Matter 官方說明；具備 BLE 與 TCP/IP 元件不等於已整合 Matter。

Matter over Thread

Thread 是低功耗 IPv6 mesh 網路。整合時需相容的 IEEE 802.15.4 無線端、Thread 堆疊及連到其他 IP 網路的 Border Router；請參考 Thread Group 官方說明。本版沒有提供可據以驗證這條完整路徑的範例。

Wi-Fi／Ethernet 傳輸

IPRO7 無內建 Wi-Fi；本版提供 ipro7_sdio_wifi 與 ipro6_if_wifi 的雙晶片連線範例。這些範例建立網路連線，尚未包含 Matter endpoint、配網或憑證管理。

OpenThread 整合範圍

需要 Thread 時，先確認目標 SoC／外接無線晶片、radio driver、平台抽象層及對應協定版本。不要將 SDK 中的 BLE Controller 函式庫視為 OpenThread 實作。

目前可用的參考範例

先以 apps/platform/ipro6_demo/ 驗證 IPRO6S Wi-Fi，或以 SDIO 雙晶片範例驗證 IPRO7 socket 連線。Matter／Thread 應用不在本版 31 個應用設定之內。

AI 與網路應用

AI 範例使用 .inm 或 .tflite 模型。把推論結果送到網路服務需自行定義資料格式、緩衝與傳輸；本版沒有 Matter NPU embedding 串流範例。

整合前需確認的設定

取得相容協定套件後，再確認工具鏈、RTOS 適配、Flash／RAM 預算、持久儲存、熵來源、憑證與 OTA 設計。不能只新增一個 Kconfig 選項就啟用未交付的堆疊。

建議驗證順序

依序驗證板級驅動、無線／Ethernet 連線、IP 傳輸及安全儲存，再進行協定整合、配網、重啟恢復與互通性測試。產品支援版本及認證狀態須以實際整合成果確認。

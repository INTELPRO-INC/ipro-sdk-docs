The IPRO SDK runs on FreeRTOS. Zephyr's role in the SDK is as the origin of the BLE Host protocol stack — blestack (GAP, GATT, L2CAP, SMP, ISO, LE Audio) is ported from Zephyr and runs on top of FreeRTOS. Applications use the Zephyr-style bt_* APIs for BLE development.

The Zephyr BLE Host architecture and bt_* API content previously on this page has been merged into the BLE Development page, which is actively maintained. You will be redirected in 3 seconds; if not, use the link above.

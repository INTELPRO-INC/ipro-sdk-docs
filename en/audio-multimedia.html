Audio & Multimedia

IPRO SDK provides comprehensive audio and multimedia capabilities, including LE Audio Bluetooth audio, USB audio devices, camera image processing, and video streaming. This page covers the architecture, APIs, and reference applications for each subsystem.

LE Audio Pipeline

LE Audio is the next-generation Bluetooth audio standard introduced in BLE 5.2. It uses ISO Channels (Isochronous Channels) to transmit audio data, replacing the traditional Classic Audio A2DP/HFP approach.

Transmit Pipeline

1
Audio Input
AUADC / I2S PCM samples
2
LC3 Encode
Audio encode 16-320 kbps
3
ISO Channel
CIS or BIS isochronous
4
BLE PHY
2M PHY wireless TX

Receive Pipeline

1
BLE PHY
2M PHY wireless RX
2
ISO Channel
CIS or BIS reassembly
3
LC3 Decode
Audio decode PCM recovery
4
Audio Output
DAC / I2S speaker out

Key Specifications

FeatureDescription
CodecLC3 (provided by the prebuilt liblc3 library)
Bitrate16 - 320 kbps (LE Audio commonly 16-124 kbps per channel)
Sample Rate8 / 16 / 24 / 32 / 48 kHz
ChannelsMono, Stereo
LatencyMeasure with stream settings and buffers end-to-end
TransportCIS (Unicast), BIS (Broadcast)

BAP Unicast Flow

Basic Audio Profile (BAP) manages audio stream establishment and control. The unicast connection flow is as follows:

1
Discover PACS
Query audio capabilities
2
PAC Records
Return codec/sample rate
3
Configure ASE
Configure stream endpoint
4
Establish CIS
Create isochronous channel
5
Enable Stream
Start audio transmission

Headset-Side Example Code

BAP Server Init (apps/bluetooth/le_audio/ipro_le_audio_headset/src/bap_server.c) 
int bap_server_init(void)
{
	int err;
	struct bt_pacs_register_param pacs_param = {
#if defined(CONFIG_BT_PAC_SNK)
		.snk_pac = true,
#endif
#if defined(CONFIG_BT_PAC_SNK_LOC)
		.snk_loc = true,
#endif
	};
	struct bt_bap_unicast_server_register_param server_param = {
		.snk_cnt = CONFIG_BT_ASCS_MAX_ASE_SNK_COUNT,
		.src_cnt = CONFIG_BT_ASCS_MAX_ASE_SRC_COUNT,
	};

	IPRO_LOGI(LOG_TAG, "Initializing BAP Unicast Server");

	/* 1. Register PACS service (must be done before publishing caps) */
	err = bt_pacs_register(&pacs_param);
	if (err != 0 && err != -EALREADY) {
		IPRO_LOGE(LOG_TAG, "Failed to register PACS (err %d)", err);
		return err;
	}
	IPRO_LOGI(LOG_TAG, "PACS service registered");

	/* 2. Register LC3 sink codec capability with PACS */
	err = bt_pacs_cap_register(BT_AUDIO_DIR_SINK, &lc3_sink_cap);
	if (err != 0) {
		IPRO_LOGE(LOG_TAG, "Failed to register sink cap (err %d)", err);
		return err;
	}
	IPRO_LOGI(LOG_TAG, "LC3 sink capability registered");

	/* 3. Set audio location (mono front left for single headset) */
	err = bt_pacs_set_location(BT_AUDIO_DIR_SINK, BT_AUDIO_LOCATION_FRONT_LEFT);
	if (err != 0) {
		IPRO_LOGE(LOG_TAG, "Failed to set sink location (err %d)", err);
		return err;
	}

	/* 4. Set supported and available audio contexts */
	bt_pacs_set_supported_contexts(BT_AUDIO_DIR_SINK,
				       BT_AUDIO_CONTEXT_TYPE_MEDIA |
				       BT_AUDIO_CONTEXT_TYPE_CONVERSATIONAL |
				       BT_AUDIO_CONTEXT_TYPE_UNSPECIFIED);

	bt_pacs_set_available_contexts(BT_AUDIO_DIR_SINK,
				       BT_AUDIO_CONTEXT_TYPE_MEDIA |
				       BT_AUDIO_CONTEXT_TYPE_CONVERSATIONAL |
				       BT_AUDIO_CONTEXT_TYPE_UNSPECIFIED);

	/* 5. Register ASCS ASE instances, then BAP callbacks. */
	err = bt_bap_unicast_server_register(&server_param);
	if (err != 0 && err != -EALREADY) {
		IPRO_LOGE(LOG_TAG, "Failed to register ASCS (err %d)", err);
		return err;
	}

	err = bt_bap_unicast_server_register_cb(&unicast_server_cb);
	if (err != 0) {
		IPRO_LOGE(LOG_TAG, "Failed to register BAP callbacks (err %d)", err);
		return err;
	}

	IPRO_LOGI(LOG_TAG, "BAP Unicast Server initialized successfully");
	return 0;
}

LC3 Codec

LC3 (Low Complexity Communication Codec) is the mandatory codec for LE Audio. It delivers better audio quality than SBC at lower bitrates. The SDK ships the LC3 codec as the prebuilt library components/3rdparty/liblc3; ipro_bt_host/upstream/zephyr/subsys/bluetooth/audio/codec.c handles LE Audio codec capability and configuration parsing.

  • Sample Rate: 8 / 16 / 24 / 32 / 48 kHz
  • Bitrate: 16 - 320 kbps (common LE Audio presets are 16 - 124 kbps per channel)
  • Frame Duration: 7.5ms or 10ms per the LE Audio standard; the bundled liblc3 additionally supports 2.5ms and 5ms
  • Channels: Mono, Stereo
  • Advantage: Matches SBC 328 kbps quality at just 160 kbps
Opus: The package includes components/3rdparty/opus for application audio codecs. LE Audio ISO streams use LC3; the earlier voice-assistant example is not included in V2.0.1.

/* Called by CherryUSB when the USB host opens the audio stream

void usbd_audio_open(uint8_t intf)
{
    /* Start isochronous DMA; send silence until audio data is available */
}

void usbd_audio_close(uint8_t intf)
{
    /* USB host closed the audio stream */
}

/* Initialize USB Audio device */
int app_uac_init(const app_uac_config_t *config)
{
    usbd_desc_register(uac_descriptor);
    usbd_add_interface(usbd_audio_init_intf(&s_intf0, 0x0100, s_entity_table, 1));
    usbd_add_interface(usbd_audio_init_intf(&s_intf1, 0x0100, s_entity_table, 1));
    usbd_add_endpoint(&s_audio_in_ep);
    usbd_event_register_callback(uac_event_handler);
    usbd_initialize();
    return 0;

Recording Path (Input):
  Microphone → AUADC → DMA → Memory Buffer → LC3 Encoder / USB

External Codec Path:
  External Codec ↔ I2S ↔ DMA ↔ Memory Buffer

Audio Output Abstraction Layer

components/audio provides a unified audio output abstraction layer, audio_output, which drives DAC, I2S, UAC, and PCM dump backends through the same API. It is the output interface used by the LE Audio reference applications. The same component also provides audio_capture (AUADC + DMA audio capture) and mp3_decoder (MP3 decoding):

Audio Output Abstraction (components/audio/include/audio_output.h) 
#include "audio_output.h"

audio_output_cfg_t cfg = {
    .type        = AUDIO_OUTPUT_DAC,            /* DAC / UAC / I2S / DUMP */
    .mode        = AUDIO_OUTPUT_MODE_STREAMING,
    .sample_rate = 48000,
    .channels    = 2,
};

audio_output_t *out = audio_output_create(&cfg);
audio_output_start(out);
audio_output_write(out, pcm, samples);   /* interleaved int16_t PCM */
audio_output_stop(out);
audio_output_destroy(out);

PDM Recording in V2.0.1

PDM capture at 16 kHz / 16-bit mono, optional LC3 streaming, persistent SMP bonding and PDS31 reconnect. V2.0.1 adds logical recordings up to 4 hours. The physical PSRAM ring retains 240 seconds; retrieve each 30-second segment using CHUNK_READY / GET_CHUNK. GET_AUDIO returns only the last 240 seconds after wrap.

Use the shipped link2 / bt52, 16 KB EM configuration. CONFIG_BT_CONN=1 remains the host limit; the controller archive has two-link capacity. Copy the complete board configuration instead of forcing these two values to match.

make -C apps/multimedia/ipro_pdm_mic_demo
make -C apps/multimedia/ipro_pdm_mic_demo BOARD=evk

EVB output uses build/build_out/; EVK output uses build_config_evk/build_out/. Both produce ipro_pdm_mic_demo_IPRO7.bin. Android source: tools/android/IproMicDemo/; matching APK and test firmware: V2.0.1 Release.

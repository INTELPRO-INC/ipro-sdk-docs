Changelog

Official release history for the IPRO SDK. For an overview of the SDK delivery package, refer to the README.md file included in the package.

IPROREL-IPRO7-V1.0.1

Release Date: March 13, 2026
Platform: IPRO7 (RISC-V RV32IMAFC)

Full IPRO7 SDK delivery package combining platform, BLE, ISP, and LE Audio, with 10 ready-to-build reference applications, a Zephyr-based BLE Host, prebuilt linkN controller library variants, and a unified build system.

Reference Applications (10)

Category Application Description
bluetooth/ble ipro_ble_remote GATT services demo (LED, Button, UART, OTA, image transfer)
bluetooth/ble ipro_ble_transparent BLE transparent data transfer with AT command interface
bluetooth/ble ipro_ble_img_capture Image capture with BLE image upload service (includes OTA)
bluetooth/ble ipro_throughput_test Bidirectional BLE throughput testing (2M PHY + DLE, up to 999 Kbps)
bluetooth/le_audio ipro_le_audio_headset GAF/BAP unicast and broadcast headset (LC3 codec)
bluetooth/le_audio ipro_le_audio_bis_source Auracast-compatible BIS broadcast source

multimedia ipro_agora_sentino Agora RTC cloud audio streaming gateway (network via Ethernet / USB NCM)
network ipro_voice_assistant AI voice assistant (speech recognition, AI conversation, speech synthesis, LCD status display, network via Ethernet (RMII) or 4G LTE modem (PPPoS))
platform ipro7_demo IPRO7 platform peripheral feature demo

BLE Stack

  • Zephyr-based BLE Host: GAP, GATT, L2CAP, SMP, ISO, LE Audio
  • Prebuilt RivieraWaves controller libraries (linkN variants):
    • Standard BLE: link1_periph, link1–link8
    • LE Audio: link1_leaudio, link2_leaudio
    • BLE 5.4 + LE Audio: link1_leaudio_53_54, link2_leaudio_53_54, link4_leaudio_53_54
    • BLE 5.3/5.4: link1_53, link1_54, link2_54
  • Pre-compiled RF driver library (ipro7_rf)
  • Pre-compiled LC3 audio codec library (liblc3)

Library Components

  • isp_algorithm — ISP image processing algorithm library
  • ipro7_rf — RF drivers used by the BLE controller
  • liblc3 — LC3 audio codec for LE Audio
  • lp_framework — Low power framework (HAL sub-library)

Build System

# List all available projects
./build_freertos.sh -l

# Build a BLE application
./build_freertos.sh ipro_ble_remote build

# Build, flash, and monitor
./build_freertos.sh ipro_ble_remote build flash monitor
Known Limitations: BLE controller source code is not included; only prebuilt linkN library variants are provided. CONFIG_BLE_FORCE_SOURCE_BUILD is not supported in this release. For advanced features, please contact the vendor.

IPRO-BLE-SDK-V0.0.1

Release Date: February 12, 2026
Platform: IPRO7 (RISC-V RV32IMAFC)

First official release of the IPRO BLE SDK, providing a complete BLE 5.4 development environment with LE Audio support. It includes 10 ready-to-build applications, a Zephyr-based BLE Host, prebuilt controller libraries, and a unified build system.

What's Included

  • BLE Applications
    • BLE Remote — GATT services demo (LED, Button, UART, OTA, image transfer)
    • Throughput Test — Bidirectional BLE throughput testing (2M PHY + DLE, up to 999 Kbps)
    • HID Keyboard — HID over GATT (HOGP) keyboard with modifier key support
    • Transparent Data — BLE transparent data transfer with AT command interface
  • LE Audio Applications
    • LE Audio Headset — GAF/BAP unicast and broadcast headset (LC3 codec)
    • BIS Broadcast Source — Auracast-compatible broadcast source
    • BIS Broadcast Sink — Broadcast sink (BASE parsing and audio resampling)
    • Walkie-Talkie — BIS-based LE Audio push-to-talk
  • ESL Applications
    • ESL Tag — Bluetooth ESL Profile compliant tag with display management
    • ESL Gateway — Access point for managing ESL tags

BLE Stack

  • Zephyr-based BLE Host: GAP, GATT, L2CAP, SMP, ISO, LE Audio
  • Prebuilt RivieraWaves controller libraries (linkN variants, link2_54 added in this release)
  • Pre-compiled RF driver library (ipro7_rf) and LC3 codec library (liblc3)
  • Removed the legacy btprofile component; applications uniformly use the Zephyr bt_* APIs

Build System

  • Unified build CLI: ./build_freertos.sh <app> build flash monitor
  • Automatic toolchain detection (vendor and standard GCC)
  • Kconfig-based configuration system

Requirements

  • RISC-V toolchain: /opt/toolchain/riscv_ipro7/
  • CMake >= 3.19
  • Ninja build system
  • Python 3.8+

Known Limitations

  • Controller source code is not included; only prebuilt library variants are provided
  • ipro_blecontroller_test (UART HCI mode) is not included as it requires controller source
  • CONFIG_BLE_FORCE_SOURCE_BUILD is not supported in this release

Documentation History

The following is a summary of development and documentation updates prior to the official releases.

February 2026

  • feat: BLE throughput optimized to 999 Kbps (improved from ~600 Kbps; connection parameter tuning and TX descriptor optimization)
  • fix: All prebuilt BLE Controller libraries updated (including TX descriptor optimization)
  • refactor: ipro_throughput_test migrated from custom wrappers to native Zephyr bt_* APIs
  • feat: BIS sink gained BASE parsing, a shared FIR resampler audio component, and a UAC DMA stall fix
  • test: Unit test suite expanded from 11 to 28 suites (147 tests), board test automation tools added
  • build: Automatic toolchain detection for vendor and standard GCC (cmake/toolchain.cmake)
  • docs: Added comprehensive README and operation manual for ipro_throughput_test

December 2025

  • feat: Image Service MTU optimization and transfer speed statistics
    • MTU calculation refined from MTU-8 to MTU-11 (4-byte safety margin added)
    • Dynamic chunk size support (236-506 bytes, based on MTU 517)
    • Performance: 56KB image transfer reaches ~40 KB/s (320 Kbps)
  • feat: MTU changes are propagated to the application automatically via the Zephyr bt_gatt_cb att_mtu_updated callback; OTA and Image Service adapt to the negotiated MTU dynamically (up to 517)
  • fix: Removed duplicate image_start_transfer() call, fixing the "Not ready" warning
  • feat: Added ipro_ble_hid_keyboard (HOGP) and ipro_walkie_talkie (BIS LE Audio) applications
  • docs: Comprehensive SDK documentation update; documentation website officially launched on GitHub Pages

September-December 2025

  • BLE: timing optimizations, PA sync fix, EM initialization consolidated to board level, static CLI command registration fix
  • USB & Audio: UAC demo with AUADC integration, CDC memory transfer command, AUADC demo, DAC speaker support
  • Multimedia: ISP sw pingpong control, DVP sensor + MJPEG demo, UVC and LCD stream control, ILI9488 SPI LCD demo
  • Network & Peripherals: EMAC Ethernet support, SD card (SDH), SPI slave demo and SPI1 support
  • System: FreeRTOS runtime statistics, frame pointer and backtrace chain, dynamic OCRAM sizing

August 2025

  • feat: BLE 5.4 support with new configuration options
  • refactor: Controller library variants renamed from mXsY to linkN
  • feat: BLE advertising workflow implementation, 40+ interactive CLI commands, IPRO logging system, OTA firmware update integration
  • refactor: Removed the obsolete RivieraWaves host stack and the legacy BLE wrapper layer

Major Milestones

  • FreeRTOS Platform - FreeRTOS-based application framework with a unified build system
  • BLE 5.4 Support - Zephyr-based BLE Host (GAP, GATT, L2CAP, SMP, ISO) + RivieraWaves prebuilt controller (linkN variants)
  • LE Audio - GAF framework and LC3 codec support

Core Features

IPRO SDK provides a complete embedded development ecosystem, from low-level drivers to high-level applications

Image Processing

Integrated ISP image pipeline, MJPEG encoding, LCD display driver for camera streaming and image recognition applications.

Voice Processing

Built-in AUADC/DAC audio subsystem with LC3 codec support, LE Audio streaming for voice recognition and audio devices.

BLE Wireless

High-performance BLE communication (up to 999 Kbps), LE Audio support, multi-link management, and OTA firmware updates.

Modular Architecture

Clean layered architecture: Application, Middleware, RTOS, BSP. Components configured independently via Kconfig system.

Development Toolchain

make -C apps/<project> quick build, build_freertos.sh build script, and CMake toolchain integration.

Reference Applications

Multiple complete reference applications demonstrating SDK capabilities and best practices

ipro_ble_remote Recommended

BLE interactive remote with 6 GATT services (LED/Button/Env/UART/PIR/OTA), image transfer 101 KB/s, OTA update 12.3 KB/s.

GATT Services OTA Image Transfer
ipro_ble_img_capture Imaging

BLE image capture application integrating the camera ISP pipeline: PIR motion detection triggers capture, images are transferred to the phone over BLE using a chunked protocol, with OTA firmware update support.

ISP Imaging PIR Trigger Image Transfer
ipro_le_audio_headset LE Audio

LE Audio headset based on GAF/BAP framework with bidirectional Unicast streaming and VCP volume control; output defaults to the DAC speaker path, with USB audio as an optional build (requires enabling CONFIG_AUDIO_OUTPUT_UAC).

GAF/BAP LC3 Codec Unicast
ipro_le_audio_bis_source

LE Audio broadcast transmitter (Auracast TX) for one-to-many audio distribution with PBP protocol and USB audio input.

Auracast TX PBP USB Audio
ipro_le_audio_bis_sink

LE Audio broadcast receiver (Auracast RX) with auto-sync to broadcast sources and USB audio output.

Auracast RX Auto-Sync USB Audio
ipro_ble_transparent

UART-to-BLE bridge module with AT command support for external MCU integration via transparent data mode.

UART Bridge AT Commands Transparent
ipro_throughput_test Testing

BLE throughput test tool using native Zephyr bt_* APIs; board-to-board testing with 2M PHY and DLE optimization reaches 999 Kbps, supporting performance benchmarking across connection parameters.

999 Kbps 2M PHY DLE
ipro_agora_sentino

AI voice conversation gateway: AMIC microphone audio is Opus-encoded and streamed in real time to the Agora RTC cloud for bidirectional voice calls with an AI bot, with LCD status display. Network connectivity is provided via Ethernet (RMII) or USB NCM.

Agora RTC Opus Bidirectional Voice
ipro_voice_assistant AI

AI voice assistant integrating microphone capture, VAD voice detection, cloud speech recognition, and TTS speech synthesis, with LCD status animation and file-system persistent memory. Network connectivity is provided via Ethernet (RMII) or a 4G LTE modem (PPPoS).

Speech Recognition TTS LCD Display
ipro7_demo Multimedia

Comprehensive platform demo with peripherals (PWM/SPI/I2C), audio (AUADC/DAC), file system, and USB.

USB Audio I/O Peripherals

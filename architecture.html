架構概覽

IPRO SDK 採用清晰的分層架構設計，提供高度模組化與可移植性，讓開發者能夠快速建構穩定的嵌入式應用。本頁詳細介紹 SDK 的系統架構、晶片規格、建構流程與元件組成。

系統總覽

SDK 的整體架構由五個主要層次組成，從上至下分別為應用層、元件層、RTOS 層、BSP 層與硬體層：

Applications (apps/)
bluetooth/ble/ bluetooth/le_audio/ multimedia/ ai/test/ platform/ipro7_demo
Components (components/)
BLE 5.4 LE Audio lwIP mbedTLS CherryUSB Audio AI EVFS LittleFS FatFS Shell LC3
RTOS (FreeRTOS / Zephyr)
FreeRTOS FreeRTOS POSIX OSAL Zephyr v4.4 (module)
BSP (bsp/)
HAL Drivers Board Config Linker Scripts Startup
Hardware (IPRO7)
RISC-V RV32IMAFC BLE Radio NPU

每一層都有明確的職責邊界：

  • 應用層：自包含的專案，每個專案擁有獨立的 .config 和 CMakeLists.txt
  • 元件層：可重用的中介軟體，透過 Kconfig 選項啟用或停用
  • RTOS 層：提供任務排程、同步原語與計時器服務；V2.1.0 起除 FreeRTOS 外，SDK 亦可作為 Zephyr v4.4.0 module 使用（見下節）
  • BSP 層：硬體抽象層與驅動程式，屏蔽不同晶片的差異
  • 硬體層：IPRO 系列 SoC 平台

FreeRTOS 與 Zephyr

V2.1.0 起，SDK 除了 FreeRTOS 建構流程外，也是一個 Zephyr v4.4.0 module（zephyr/module.yml）；SDK 根目錄的 west.yml 使 SDK 成為 west manifest repository。兩條路徑使用相同的 HAL 與 SoC 驅動，Zephyr 端透過 Zephyr 的 device driver API 提供。

項目 FreeRTOS Zephyr
應用／範例apps/ 下 34 個應用zephyr/samples/ 範例與 Zephyr 上游範例；驅動測試位於 zephyr/tests/
建構make -C apps/<category>/<project> 或 ./build_freertos.shtools/zephyr/bootstrap.sh 建立 workspace 後以 west build 建構
板卡IPRO7 EVB、IPRO7AI EVK、IPRO7AI Reef EVKipro7_evb、ipro7ai_evk
Bluetooth LEZephyr v4.4 Host 經移植層執行於 FreeRTOS，搭配 IPRO BLE 預編譯控制器Zephyr Host 搭配同一組 IPRO BLE 預編譯控制器
IEEE 802.15.4／ThreadV2.1.0 未提供Zephyr IEEE 802.15.4 驅動與 OpenThread
低功耗、顯示、攝影機、音訊 codec、USB、SD Host、Ethernet、NPU提供尚未提供，請使用 FreeRTOS（EVK LCD 可透過 Zephyr 的 ST7789V 驅動使用）

提示：支援板卡、燒錄方式、範例與尚未支援的功能，請見 Zephyr RTOS。

雙晶片架構

IPRO7 不內建 Wi-Fi。需要 Wi-Fi 連網的產品採用雙晶片架構：IPRO7 作為主控 SoC，負責應用邏輯、AI/NPU 推論、BLE、音訊與周邊控制；Wi-Fi 連網由外接的 SDIO Wi-Fi companion 提供。V2.1.0 提供 ATBM6162 SDIO 模組探測（ipro_atbm_probe）、SDIO Host Wi-Fi 參考應用 ipro7_sdio_wifi，以及 IPRO7AI Reef EVK 搭配 IPRO6S FIN 卡的 Host 端（ipro7ai_reef_demo 的 defconfig_wifi_ipro6s）。

配置系統（Kconfig）

SDK 使用 Linux kernel 風格的 Kconfig 系統管理專案配置。每個應用擁有自己的 .config 檔案，建構時自動生成 build/include/generated/autoconf.h 供 C 程式碼使用。

配置層次

  1. 選項定義：根 Kconfig 與各元件的 Kconfig - 定義所有可用選項
  2. 專案預設值：apps/<project>/defconfig - 專案預設配置，由 make defconfig 載入
  3. 實際建構配置：apps/<project>/.config - 應用專屬配置（最高優先級）
defconfig 工作流程 
cd apps/bluetooth/ble/ipro_ble_remote

# 由專案 defconfig 生成 .config
make defconfig

# 修改 .config 後，將最小化配置存回 defconfig
make savedefconfig

關鍵配置選項

.config 範例 
# SoC 選擇
CONFIG_IPRO7=y
CONFIG_CPU_ID="intelpro_ipro7"

# RTOS 選擇
CONFIG_FREERTOS_SUPPORT=y

# 無線功能
CONFIG_BLUETOOTH_LE_ENABLE=y

# 元件啟用
CONFIG_COMPONENTS_LWIP_ENABLE=y
CONFIG_COMPONENTS_MBEDTLS_ENABLE=y

# 測試自動執行
CONFIG_TEST_AUTO_RUN=y

配置與程式碼的關係

build/include/generated/autoconf.h（自動生成） 
/* 由 Kconfig 自動生成，請勿手動編輯 */
#define CONFIG_IPRO7 1
#define CONFIG_CPU_ID "intelpro_ipro7"
#define CONFIG_FREERTOS_SUPPORT 1
#define CONFIG_BLUETOOTH_LE_ENABLE 1
#define CONFIG_COMPONENTS_LWIP_ENABLE 1
提示：CONFIG_CPU_ID 必須在 .config 中正確設定，cmake/toolchain.cmake 才能偵測到正確的架構旗標。工具鏈偵測邏輯會自動區分 vendor GCC（含 _xxldsp DSP 擴充指令）與標準 GCC，並據此調整編譯旗標。

最小 main.c 骨架

所有 FreeRTOS 應用共用 components/os/freertos/freertos_app_hooks.{c,h} 元件，heap、FreeRTOS hooks（idle/tick/stack-overflow/malloc-failed）與 assert 皆以 weak symbol 形式提供預設實作，應用程式的 main.c 不需要重複這些樣板程式碼：

最小 main.c 
#include "freertos_app_hooks.h"
#include <FreeRTOS.h>
#include <task.h>

static void app_task(void *arg)
{
    /* 應用程式主邏輯 */
    for (;;) {
        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}

int main(void)
{
    ipro_platform_init();   /* heap + boot2 + log + shell 初始化 */
    xTaskCreate(app_task, "app", 1024, NULL, 5, NULL);
    vTaskStartScheduler();
    while (1) {}
}
提示：若需客製某個 hook（例如 vApplicationIdleHook），直接在應用程式原始碼中定義同名的非 weak 版本即可，連結器會自動採用，不需修改共用元件。

基本 BLE 選擇 CONFIG_IPRO_BLE_CTLR_FEATURE="bt52"；BLE 5.4 與兩路 ISO 串流（CIS/BIS）選擇 "bt54_iso2"，後者要求 CONFIG_EM_SIZE 至少 32 KB。Host 連線上限不可超過控制器容量；PDM 請保留 link2／CONFIG_BT_CONN=1 配置。

Host 提供原始碼。V2.1.0 的控制器套件含 16 個 IPRO7 預編譯函式庫（link1_periph / link1 / link2 / link4 × bt52 / bt54_iso2 × debug / release），依配置選用；6 個 IPRO6S BR/EDR 函式庫僅收錄於 V2.0.1。以 Zephyr RTOS 建構時，Zephyr Host 使用同一組 IPRO7 預編譯控制器函式庫。

BSP 與驅動

Board Support Package 位於 bsp/ 目錄，提供硬體抽象與週邊驅動：

  • bsp/hal/ - 硬體抽象層 API
  • bsp/hal/lp_framework/ - 低功耗框架（PDS/HBN 睡眠模式管理，以預建函式庫形式提供）
  • bsp/drivers/ - 週邊驅動程式
  • bsp/board/ - 板級配置（腳位映射、時脈設定）
  • bsp/common/ - 啟動程式碼、連結腳本、共用程式碼

支援的週邊驅動

# 開始使用

依序完成這幾頁，即可在 IPRO7AI Reef EVK 上建置、燒錄第一個應用並看到主控台輸出。

<div class="grid cards" markdown>

-   :material-sign-direction:{ .lg } **[選擇開發環境](environment.md)**

    ---

    SDK 下載、硬體與軟體需求，以及 Windows（VS Code）與 macOS／Linux（命令列）兩種環境的差異。

-   :material-microsoft-windows:{ .lg } **[Windows 安裝與 VS Code](windows.md)**

    ---

    以 Online Installer 安裝工具與 VS Code Extension，並切換到 SDK V2.1.0。

-   :material-console:{ .lg } **[macOS／Linux 命令列](command-line.md)**

    ---

    安裝工具鏈與建置工具、解壓 SDK，並確認可以建置。

-   :material-developer-board:{ .lg } **[第一個 FreeRTOS 應用](first-app-freertos.md)**

    ---

    在 Reef EVK 上建置、燒錄 `ipro7ai_reef_demo`，並以 `reef selftest` 檢查板上功能。

-   :material-layers-outline:{ .lg } **[第一個 Zephyr 應用](first-app-zephyr.md)**

    ---

    建立 Zephyr 工作區，在 IPRO7 EVB 或 IPRO7AI EVK 上建置並燒錄 `hello_world`。

-   :material-usb-port:{ .lg } **[燒錄與序列埠](flash-and-monitor.md)**

    ---

    IntelProCube 命令列工具、各板燒錄設定、`build_freertos.sh flash`，以及主控台鮑率。

</div>

# Get Started

Work through these pages in order to build and flash your first application on the IPRO7AI Reef EVK and see it on the console.

<div class="grid cards" markdown>

-   :material-sign-direction:{ .lg } **[Choose Your Environment](environment.md)**

    ---

    Download the SDK, check the hardware and software you need, and compare Windows (VS Code) with macOS / Linux (command line).

-   :material-microsoft-windows:{ .lg } **[Windows Setup & VS Code](windows.md)**

    ---

    Install the tools and the VS Code Extension with the Online Installer, then switch to SDK V2.1.0.

-   :material-console:{ .lg } **[macOS / Linux Command Line](command-line.md)**

    ---

    Install the toolchain and build tools, unpack the SDK and make sure it builds.

-   :material-developer-board:{ .lg } **[First FreeRTOS Application](first-app-freertos.md)**

    ---

    Build and flash `ipro7ai_reef_demo` on the Reef EVK and check the board with `reef selftest`.

-   :material-layers-outline:{ .lg } **[First Zephyr Application](first-app-zephyr.md)**

    ---

    Create the Zephyr workspace, then build and flash `hello_world` on the IPRO7 EVB or IPRO7AI EVK.

-   :material-usb-port:{ .lg } **[Flashing & Serial Console](flash-and-monitor.md)**

    ---

    The IntelProCube command-line tool, per-board flash settings, `build_freertos.sh flash` and console baud rates.

</div>

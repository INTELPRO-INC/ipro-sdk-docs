網路開發

IPRO7 是系統的主控 SoC，負責應用邏輯、NPU 推論與 BLE 連線，本身不內建 Wi-Fi 射頻。IPRO SDK 透過 lwIP TCP/IP 協定堆疊與 mbedTLS 加密程式庫，提供兩條對外連網路徑：

  • 乙太網路 (EMAC) — IPRO7 內建 Ethernet MAC 控制器，搭配 lwIP 即可有線上網。Release SDK v1.0.1 內含完整原始碼與參考應用。
  • Wi-Fi（經 IPRO6 companion 晶片） — Wi-Fi 6 (802.11ax) 由 IPRO6 系列 connectivity companion 晶片提供，經 SDIO 介面橋接至 IPRO7 的 lwIP 堆疊。完整方案需另行取得，請聯絡原廠。

此外，SDK 亦提供 LTE modem PPP 撥號（components/network/lte_modem/，UART AT 介面）作為 EMAC 以外的廣域網路選項。

概覽

TCP/IP 協定堆疊

  • lwIP 輕量化 TCP/IP 堆疊
  • TCP / UDP Socket API (BSD 風格)
  • DHCP 用戶端與伺服器
  • DNS / SNTP / Ping

乙太網路 (EMAC)

  • IPRO7 內建 Ethernet MAC 控制器
  • 外接 PHY 即可有線上網
  • DHCP 自動取得 IP
  • Release SDK 內含參考應用

安全與加密

  • mbedTLS 2.28 LTS (TLS 1.2 / DTLS 1.2)
  • X.509 憑證管理
  • 硬體加速大數運算
  • HTTPS / 安全 IoT 通訊

Wi-Fi（IPRO6 Companion）

  • Wi-Fi 6 (802.11ax) 由 IPRO6 晶片提供
  • SDIO 介面連接 IPRO7 主控
  • 數據面橋接至 IPRO7 lwIP
  • 完整方案請聯絡原廠取得

網路架構

IPRO SDK 的網路子系統採用分層架構。EMAC 與 SDIO Wi-Fi 橋接共用同一個 lwIP 堆疊，應用層程式碼不需因實體介面不同而改寫：

┌─────────────────────────────────────────────────┐
│      應用層 (HTTP Client, MQTT, CoAP, ...)       │
├─────────────────────────────────────────────────┤
│      TLS / DTLS (mbedTLS 2.28 LTS)               │
│      components/crypto/mbedtls/                  │
├─────────────────────────────────────────────────┤
│      TCP / UDP (lwIP Socket API)                 │
│    ┌─────┬──────┬───────┬────────┐              │
│    │DHCP │ DNS  │ SNTP  │  Ping  │              │
│    └─────┴──────┴───────┴────────┘              │
│      components/network/lwip/                    │
├──────────────────────┬──────────────────────────┤
│  EMAC 驅動           │  SDIO 網路橋接            │
│  (乙太網路)          │  IPRO7 SDH ↔ IPRO6        │
│  bsp/.../drv_emac.c  │  (需聯絡原廠取得)         │
├──────────────────────┴──────────────────────────┤
│  Ethernet PHY        │  IPRO6 Wi-Fi 6 Companion  │

網路配置

在應用程式的 .config 檔案中啟用網路相關功能：

.config - 網路配置 
# 啟用 lwIP TCP/IP 堆疊
CONFIG_COMPONENTS_LWIP_ENABLE=y
CONFIG_COMPONENTS_LWIP_APP_ENABLE=y

# 啟用 ping 指令 (網路診斷)
CONFIG_PING=y

# 啟用乙太網路 (EMAC)
CONFIG_ETHERNET=y

# 啟用 mbedTLS 加密支援
CONFIG_COMPONENTS_MBEDTLS_ENABLE=y
提示：以上配置與 Release SDK 內的 apps/platform/ipro7_demo 一致，可直接以該專案的 .config 為起點。

lwIP 整合

IPRO SDK 整合 lwIP (Lightweight IP) 作為 TCP/IP 協定堆疊，提供標準的 BSD Socket API，讓開發者可以使用熟悉的 socket 程式設計介面。

Socket API 範例

TCP 用戶端連線 
#include <lwip/sockets.h>
#include <lwip/netdb.h>

int tcp_client_example(const char *host, uint16_t port)
{
    struct sockaddr_in server_addr;
    int sock;

    /* 建立 TCP socket */
    sock = socket(AF_INET, SOCK_STREAM, 0);
    if (sock < 0) {
        printf("Socket 建立失敗\r\n");
        return -1;
    }

    /* DNS 解析主機名稱 */
    struct hostent *hp = gethostbyname(host);
    if (!hp) {
        printf("DNS 解析失敗: %s\r\n", host);
        close(sock);
        return -1;
    }

    /* 連線至伺服器 */
    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_port = htons(port);
    memcpy(&server_addr.sin_addr, hp->h_addr, hp->h_length);

    if (connect(sock, (struct sockaddr *)&server_addr,
                sizeof(server_addr)) < 0) {
        printf("連線失敗\r\n");
        close(sock);
        return -1;
    }

    /* 傳送資料 */
    const char *msg = "Hello from IPRO7!";
    send(sock, msg, strlen(msg), 0);

    /* 接收回應 */
    char buf[256];
    int len = recv(sock, buf, sizeof(buf) - 1, 0);
    if (len > 0) {
        buf[len] = '\0';
        printf("收到回應: %s\r\n", buf);
    }

    close(sock);
    return 0;
}
UDP 傳送範例 
#include <lwip/sockets.h>

int udp_send_example(const char *dest_ip, uint16_t port)
{
    int sock = socket(AF_INET, SOCK_DGRAM, 0);
    if (sock < 0) return -1;

    struct sockaddr_in dest;
    memset(&dest, 0, sizeof(dest));
    dest.sin_family = AF_INET;
    dest.sin_port = htons(port);
    inet_aton(dest_ip, &dest.sin_addr);

    const char *data = "UDP packet from IPRO7";
    sendto(sock, data, strlen(data), 0,
           (struct sockaddr *)&dest, sizeof(dest));

    close(sock);
    return 0;
}

乙太網路 (EMAC)

IPRO7 內建 EMAC (Ethernet MAC) 控制器，外接 Ethernet PHY 即可支援有線網路連線，適用於閘道器、工業控制等需要有線網路的應用場景。這是 Release SDK v1.0.1 內建議的主要連網路徑。

EMAC 初始化與 lwIP 註冊 
#include <hal_emac.h>
#include <hal_ethernetif.h>
#include <lwip/tcpip.h>

static struct netif emac_netif;

static void emac_netif_setup(void *arg)
{
    struct netif *netif = (struct netif *)arg;
    ip4_addr_t ipaddr, netmask, gw;

    /* 使用 DHCP (位址設為 0) */
    ip_addr_set_zero(&ipaddr);
    ip_addr_set_zero(&netmask);
    ip_addr_set_zero(&gw);

    /* 註冊網路介面 */
    netif_add(netif, &ipaddr, &netmask, &gw,
              NULL, ethernetif_init, tcpip_input);
    netif_set_default(netif);
    ethernet_link_status_updated(netif);

    /* 啟動 DHCP 用戶端 */
    netifapi_dhcp_start(netif);
}

void emac_init(void)
{
    memset(&emac_netif, 0, sizeof(emac_netif));
    tcpip_init(emac_netif_setup, &emac_netif);
}

啟用乙太網路需在 .config 中設定 CONFIG_ETHERNET=y，驅動位於 bsp/drivers/ipro7_soc/std_drv/src/drv_emac.c。參考應用 apps/platform/ipro7_demo 在開機時自動執行 emac_lwip 指令完成上述流程。

安全加密 (mbedTLS)

IPRO SDK 整合 mbedTLS 2.28 LTS 程式庫，提供 TLS/DTLS 安全通訊能力以及各種密碼學演算法。

功能特性

  • TLS 1.2 - 安全的 TCP 連線加密
  • DTLS 1.2 - 基於 UDP 的安全通訊 (適用於 CoAP 等協定)
  • X.509 憑證 - 伺服器與用戶端憑證驗證
  • 對稱加密 - AES-128/192/256, ChaCha20-Poly1305
  • 雜湊函式 - SHA-256, SHA-384, SHA-512
  • 非對稱加密 - RSA, ECDSA, ECDH (secp256r1, secp384r1)
  • 隨機數產生 - CTR-DRBG
  • 硬體加速 - 大數運算硬體加速 (CONFIG_MBEDTLS_BIGNUM_USE_HW=y)
TLS 用戶端連線範例 
#include "mbedtls/net_sockets.h"
#include "mbedtls/ssl.h"
#include "mbedtls/entropy.h"
#include "mbedtls/ctr_drbg.h"

int tls_connect_example(const char *hostname, const char *port)
{
    mbedtls_net_context server_fd;
    mbedtls_ssl_context ssl;
    mbedtls_ssl_config conf;
    mbedtls_entropy_context entropy;
    mbedtls_ctr_drbg_context ctr_drbg;

    /* 初始化 */
    mbedtls_net_init(&server_fd);
    mbedtls_ssl_init(&ssl);
    mbedtls_ssl_config_init(&conf);
    mbedtls_entropy_init(&entropy);
    mbedtls_ctr_drbg_init(&ctr_drbg);

    /* 設定亂數產生器 */
    mbedtls_ctr_drbg_seed(&ctr_drbg, mbedtls_entropy_func,
                          &entropy, NULL, 0);

    /* TCP 連線 */
    mbedtls_net_connect(&server_fd, hostname, port,
                        MBEDTLS_NET_PROTO_TCP);

    /* TLS 設定 */
    mbedtls_ssl_config_defaults(&conf, MBEDTLS_SSL_IS_CLIENT,
                                MBEDTLS_SSL_TRANSPORT_STREAM,
                                MBEDTLS_SSL_PRESET_DEFAULT);
    mbedtls_ssl_conf_rng(&conf, mbedtls_ctr_drbg_random, &ctr_drbg);
    mbedtls_ssl_setup(&ssl, &conf);
    mbedtls_ssl_set_hostname(&ssl, hostname);

    /* 綁定 socket */
    mbedtls_ssl_set_bio(&ssl, &server_fd,
                        mbedtls_net_send, mbedtls_net_recv, NULL);

    /* 執行 TLS 交握 */
    int ret = mbedtls_ssl_handshake(&ssl);
    if (ret != 0) {
        printf("TLS 交握失敗: -0x%04X\r\n", -ret);
        goto cleanup;
    }

    /* 透過 TLS 傳送資料 */
    const char *request = "GET / HTTP/1.1\r\nHost: example.com\r\n\r\n";
    mbedtls_ssl_write(&ssl, (const unsigned char *)request,
                      strlen(request));

cleanup:
    mbedtls_ssl_close_notify(&ssl);
    mbedtls_net_free(&server_fd);
    mbedtls_ssl_free(&ssl);
    mbedtls_ssl_config_free(&conf);
    mbedtls_entropy_free(&entropy);
    mbedtls_ctr_drbg_free(&ctr_drbg);
    return ret;
}

HTTP Client

⚠ Release SDK 注意事項：高階 HTTP/HTTPS 用戶端元件 components/http_client/ 未包含在 Release SDK v1.0.1 中。以下內容僅供架構參考，如需此元件請聯絡原廠取得。

components/http_client/ 是建構於 lwIP 與 mbedTLS 之上的高階 HTTP/HTTPS 用戶端元件，免去手動管理 socket 與 TLS 交握的細節：

  • 連線池 - 重複使用 TCP/TLS 連線，降低重複交握成本
  • TLS 支援 - HTTPS 請求（內部使用 mbedTLS）
  • Multipart 編碼 - 支援檔案/表單上傳
  • Keep-Alive 與逾時管理 - 可調整

在 Release SDK v1.0.1 中，參考應用 apps/network/ipro_voice_assistant 並未使用此元件，而是採用應用內建的 HTTP/TLS 實作（src/net/iva_http_client.c、src/net/iva_tls.c，同樣建構於 lwIP 與 mbedTLS 之上）進行 TLS/HTTPS 通訊，可作為自行實作 HTTPS 用戶端的參考。

Wi-Fi（經 IPRO6 Companion 晶片）

⚠ Release SDK 注意事項：SDIO Wi-Fi 橋接方案（含 IPRO7 端 sdiowifi 橋接元件、IPRO6 端韌體與主機端參考設計）未包含在 Release SDK v1.0.1 中。以下內容僅供架構參考，完整方案請聯絡原廠取得。

IPRO7 本身不具備 Wi-Fi 射頻。需要 Wi-Fi 連線的產品採用雙晶片架構：IPRO7 作為主控 SoC，搭配 IPRO6 系列 connectivity companion 晶片提供 Wi-Fi 6 (802.11ax) 連線能力。

雙晶片 Wi-Fi 架構 
┌───────────────────────────┐        ┌───────────────────────────┐
│        IPRO7 (主控)        │        │   IPRO6 (Wi-Fi Companion) │
│                           │        │                           │
│  應用 / NPU / BLE          │  SDIO  │  Wi-Fi 6 (802.11ax)       │
│  lwIP netif ──── SDH ─────┼────────┼── SDIO 網路橋接韌體        │
│  (數據面進入 lwIP 堆疊)    │ 4-bit  │  (STA 連線 / 認證)         │
└───────────────────────────┘        └───────────────────────────┘
  • 實體介面 - IPRO7 以內建 SDH (SDIO Host) 控制器作為 SDIO 主機，IPRO6 作為 SDIO 從機。
  • 數據面 - Wi-Fi 封包經 SDIO 橋接至 IPRO7 端的 lwIP 網路介面，應用程式使用與 EMAC 相同的 Socket API，無需修改。
  • 控制面 - Wi-Fi 連線管理（掃描、認證、漫遊）由 IPRO6 端韌體處理。
  • SDK 元件 - components/network/sdiowifi/ SDIO 網路橋接元件未包含於 Release SDK v1.0.1；完整方案（含橋接元件、IPRO6 端韌體、主機端參考設計）請聯絡原廠取得。

評估雙晶片 Wi-Fi 方案（硬體參考設計、IPRO6 韌體、量產支援）請聯絡原廠。

核心功能

IPRO SDK 提供完整的嵌入式開發生態系統，從底層驅動到高階應用一應俱全

影像處理

整合 ISP 影像處理管線、MJPEG 編碼、LCD 顯示驅動，支援攝影機串流與影像辨識應用。

語音處理

內建 AUADC/DAC 音訊子系統，支援 LC3 編解碼、LE Audio 串流，適用於語音辨識與音訊裝置開發。

BLE 無線通訊

高效能 BLE 通訊（最高 999 Kbps），支援 LE Audio、多連線管理、OTA 韌體更新。

模組化架構

清晰的分層架構設計：應用層、中介軟體、RTOS、BSP。各元件透過 Kconfig 系統彈性設定。

開發工具鏈

提供 make -C apps/<project> 快速建構、build_freertos.sh 建構腳本、CMake 工具鏈整合，以及 tools/serial_monitor.py 序列埠監看工具。

Zephyr RTOS

SDK 同時是 Zephyr v4.4.0 模組，支援 IPRO7 EVB 與 IPRO7AI EVK：周邊驅動、BLE、IEEE 802.15.4／OpenThread（Thread）與 MCUboot。

Windows Online Installer 3.4.0：首次安裝與獨立更新 · Extension 3.3.0：控制中心、Build／Flash／Monitor

快速開始

選擇您偏好的開發方式，幾分鐘內開始建構應用

FreeRTOS 建構指令 
# 使用 Make 建構（推薦）
make -C apps/bluetooth/ble/ipro_ble_remote

# 或使用建構腳本
./build_freertos.sh ipro_ble_remote build
提示：建構產出位於 apps/<category>/<name>/build/build_out/ 目錄。
Zephyr RTOS（IPRO7 EVB／IPRO7AI EVK） 
tools/zephyr/bootstrap.sh
source zephyr-workspace/env.sh
cd zephyr-workspace
west build -b ipro7_evb zephyr/samples/hello_world
west flash
FreeRTOS 為主要開發路徑，34 個應用皆以 FreeRTOS 建構。Zephyr 的環境需求、燒錄方式與支援範圍請見 Zephyr RTOS。

IPRO-SDK-V2.1.0

發行日期：2026-10-15

新增 Zephyr RTOS 支援，FreeRTOS 應用聚焦 IPRO7，共 34 個應用專案。

  • SDK 同時是 Zephyr v4.4.0 模組，支援 ipro7_evb 與 ipro7ai_evk：驅動程式、Bluetooth LE（Zephyr Host + IPRO BLE Controller）、IEEE 802.15.4 與 OpenThread、MCUboot 及經 BLE 的映像檔上傳。詳見 Zephyr RTOS。
  • Thread 於 Zephyr 提供；RF 驅動程式與 IEEE 802.15.4 MAC 以 Zephyr 預編譯函式庫交付（lib/zephyr/）。
  • 新增應用：ipro7ai_reef_demo（IPRO7AI Reef EVK）、ipro7ai_evk_launcher、ipro7ai_evk_person_detect、ipro7ai_evk_rps、ipro7_uvc_cam、ipro_ai_link。
  • AI 執行庫可從 SD 卡載入模型；預編譯函式庫不再包含建構環境的檔案路徑。
  • 隨附 tools/serial_monitor.py、tools/zephyr/ 與 tools/create_ota.py。
  • 不含 IPRO6S 應用、IPRO6S BLE Controller 函式庫與 ipro6_rf，IPRO6S 開發請使用 V2.0.1；Matter 與 FreeRTOS 應用的 Thread 未包含。
  • V2.0.9（2026-10-15）為 V2.1.0 之前的 IPRO7 封裝版本，不含 Zephyr。
  • 打包驗證：34 個 FreeRTOS 應用全數建置成功；Zephyr 範例矩陣與 twister（zephyr/samples、zephyr/tests）以發行包於 ipro7_evb、ipro7ai_evk 建置通過。以上為建置驗證，不代表板上測試結果。

IPRO-SDK-V2.0.1

發行日期：2026-09-09

延續 V2.0 的 IPRO6S 支援及 31 個應用專案，修正長時間 BLE 音訊傳輸。

  • 修正連續傳輸時 Bluetooth Host queue 發布的原子性問題。
  • PDM 邏輯錄音最長 4 小時，PSRAM ring 保留 240 秒，每 30 秒自動分段傳輸；Android 在分段間維持高連線優先權。
  • PDM 改用 link2 控制器、單連線 Host 與 2M PHY，提供 EVB／EVK 配置與 Android 配套原始碼。
  • 包含 IPRO6S Wi-Fi／BR/EDR 範例、SDIO 雙端韌體、NPU／TFLM 範例及 .inm／.tflite 模型。
  • 包含 ipro_unit_test 與 Linux x86-64 CMake；1.2.1 的 serial_monitor.py 與 PREBUILT-ARCHIVES-STRIPPED.txt 已不在此包。

正式發行紀錄記載 31/31 應用建置成功，並以 Pixel 7a + IPRO7AI 完成五分鐘錄音：十個 960,000-byte 區塊、無掉包或序號缺口、ring 覆寫成功，穩態傳輸為 84.2–91.2 KB/s。數值對應該測試組合，不代表所有板子與手機皆有相同結果。發行說明、SDK、APK 與測試韌體

IPRO-IPRO7-SDK-V1.2.1

釋出日期: 2026-09-08

以下內容依交付包的 VERSION.txt、建構配置與實際檔案核對。

  • Zephyr 4.4 Host 位於 ipro_bt_host；RivieraWaves v14.0.2 Controller 位於 ipro_ble_controller。
  • 16 個 Controller 預編譯函式庫：4 種 ACL 配置 × 2 種功能配置 × debug/release 組合；不包含 Controller 實作原始碼。
  • 包含 IPRO7 端 ipronet_host、sdiowifi 元件與 ipro7_sdio_wifi 範例；相容 IPRO6S 韌體需另行取得。

  • 已隨附 tools/serial_monitor.py；燒錄工具、板級測試腳本、當機解析工具與 OpenOCD 配置仍需另行取得。

IPROREL-IPRO7-V1.0.1

釋出日期：2026 年 3 月 13 日
平台：IPRO7（RISC-V RV32IMAFC）

IPRO7 完整 SDK 交付包，整合 platform、BLE、ISP 與 LE Audio，包含 9 個可直接編譯的參考應用、Zephyr-based BLE Host、prebuilt linkN controller 函式庫變體與統一建置系統。

參考應用（9 個）

分類 應用 說明
bluetooth/ble ipro_ble_remote GATT 服務示範（LED、Button、UART、OTA、影像傳輸）
bluetooth/ble ipro_ble_transparent BLE 透明資料傳輸，含 AT 指令介面
bluetooth/ble ipro_ble_img_capture 影像擷取與 BLE 影像上傳服務（含 OTA）
bluetooth/ble ipro_throughput_test 雙向 BLE 吞吐量測試（2M PHY + DLE，最高 999 Kbps）
bluetooth/le_audio ipro_le_audio_headset GAF/BAP 單播與廣播耳機（LC3 編解碼）
bluetooth/le_audio ipro_le_audio_bis_source Auracast 相容 BIS 廣播音源
bluetooth/le_audio ipro_le_audio_bis_sink BIS 廣播接收端（BASE 解析與音訊重取樣）
multimedia ipro_agora_sentino Agora RTC 雲端音訊串流閘道（經 Ethernet / USB NCM 連網）
platform ipro7_demo IPRO7 平台周邊功能示範

BLE 協定棧

  • Zephyr-based BLE Host：GAP、GATT、L2CAP、SMP、ISO、LE Audio
  • 預編譯 RivieraWaves Controller 函式庫（linkN 變體）：
    • 標準 BLE：link1_periph、link1–link8
    • LE Audio：link1_leaudio、link2_leaudio
    • BLE 5.4 + LE Audio：link1_leaudio_53_54、link2_leaudio_53_54、link4_leaudio_53_54
    • BLE 5.3/5.4：link1_53、link1_54、link2_54
  • 預編譯 RF 驅動函式庫（ipro7_rf）
  • 預編譯 LC3 音訊編解碼函式庫（liblc3）

函式庫元件

  • isp_algorithm — ISP 影像處理演算法函式庫
  • ipro7_rf — BLE Controller 使用的 RF 驅動
  • liblc3 — LE Audio 使用的 LC3 音訊編解碼
  • lp_framework — 低功耗框架（HAL 子函式庫）

建置系統

# 列出所有可建置的專案
./build_freertos.sh -l

# 建置 BLE 應用
./build_freertos.sh ipro_ble_remote build

# 建置、燒錄並監看
./build_freertos.sh ipro_ble_remote build flash monitor
已知限制：BLE Controller 原始碼不隨包提供，僅提供 prebuilt linkN 函式庫變體；CONFIG_BLE_FORCE_SOURCE_BUILD 在本版本不支援。如需進階功能，請聯絡 INTELPRO取得。

IPRO-BLE-SDK-V0.0.1

釋出日期：2026 年 2 月 12 日
平台：IPRO7（RISC-V RV32IMAFC）

IPRO BLE SDK 首次正式釋出，提供完整的 BLE 5.4 開發環境與 LE Audio 支援，包含 10 個可直接編譯的應用、Zephyr-based BLE Host、prebuilt controller 函式庫與統一建置系統。

內含應用

  • BLE 應用
    • BLE Remote — GATT 服務示範（LED、Button、UART、OTA、影像傳輸）
    • Throughput Test — 雙向 BLE 吞吐量測試（2M PHY + DLE，最高 999 Kbps）
    • HID Keyboard — HID over GATT（HOGP）鍵盤，支援修飾鍵
    • Transparent Data — BLE 透明資料傳輸，含 AT 指令介面
  • LE Audio 應用
    • LE Audio Headset — GAF/BAP 單播與廣播耳機（LC3 編解碼）
    • BIS Broadcast Source — Auracast 相容廣播音源
    • BIS Broadcast Sink — 廣播接收端（BASE 解析與音訊重取樣）
    • Walkie-Talkie — 基於 BIS 的 LE Audio 按鍵通話
  • ESL 應用
    • ESL Tag — 符合 Bluetooth ESL Profile 的電子標籤（含顯示管理）
    • ESL Gateway — 管理 ESL 標籤的存取點（AP）

BLE 協定棧

  • Zephyr-based BLE Host：GAP、GATT、L2CAP、SMP、ISO、LE Audio
  • 預編譯 RivieraWaves Controller 函式庫（linkN 變體，本版新增 link2_54）
  • 預編譯 RF 驅動函式庫（ipro7_rf）與 LC3 編解碼函式庫（liblc3）
  • 移除 legacy btprofile 元件，應用層統一使用 Zephyr bt_* API

建置系統

  • 統一建置 CLI：./build_freertos.sh <app> build flash monitor
  • 自動偵測 vendor 與標準 GCC 工具鏈
  • Kconfig 配置系統

系統需求

  • RISC-V 工具鏈：/opt/toolchain/riscv_ipro7/
  • CMake >= 3.19
  • Ninja 建置系統
  • Python 3.8+

已知限制

  • Controller 原始碼不隨包提供，僅提供 prebuilt 函式庫變體
  • ipro_blecontroller_test（UART HCI 模式）不包含在內，因其需要 controller 原始碼
  • CONFIG_BLE_FORCE_SOURCE_BUILD 在本版本不支援
